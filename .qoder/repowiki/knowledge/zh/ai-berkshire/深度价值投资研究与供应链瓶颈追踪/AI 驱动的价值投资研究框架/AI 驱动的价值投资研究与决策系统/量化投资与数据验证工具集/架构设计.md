- **模块化独立设计**：模块由多个高内聚的 Python 脚本（如 `financial_rigor.py`, `momentum_backtest.py`）和一个 Shell 脚本（`log-command.sh`）组成，各脚本通过 CLI 接口独立运行，无内部包依赖。
- **零外部依赖架构**：核心财务工具（`financial_rigor.py`, `report_audit.py`）严格仅使用 Python 标准库（`decimal`, `json`, `argparse`），确保在无网络或受限环境下的可移植性与计算精确性。
- **分层筛选逻辑**：选股与回测工具（`stock_screener.py`, `momentum_backtest_v2.py`）采用“动量发现（技术面）+ 价值验证（基本面）”的双层架构，通过硬编码或本地 JSON 文件管理基本面数据，结合 Yahoo Finance API 获取价格数据。
- **异步爬虫引擎**：`xueqiu_scraper.py` 基于 `playwright` 构建异步浏览器自动化流程，实现登录态持久化、断点续爬及双通道数据获取（JS fetch + APIRequestContext），以应对反爬机制。
