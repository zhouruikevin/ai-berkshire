该仓库（AI Berkshire）是一个基于文档和脚本的价值投资研究框架，而非传统的软件应用系统。因此，它没有传统意义上的代码级错误处理（如 try-catch、异常类定义或全局错误中间件）。其“错误处理”体现为**业务逻辑层面的数据验证、交叉比对与准出/打回机制**，旨在确保投资研究报告的客观性与准确性。

### 1. 核心策略：防御性计算与多源交叉验证
由于缺乏后端服务，系统的“容错”主要依赖于工具链对输入数据的严格校验和对输出结果的审计。

*   **精确十进制计算**：在 `tools/financial_rigor.py` 中，所有财务计算均使用 Python 的 `decimal.Decimal` 模块，避免浮点数精度误差导致的“计算错误”。
*   **多源交叉验证 (Cross-Validation)**：通过对比不同信源（如年报、Yahoo Finance、StockAnalysis）的数据，计算偏差率。若偏差超过阈值（默认 2%），则标记为“❌ 警告”，提示人工核实。
*   **Benford 定律检测**：用于识别财务数据是否存在人为造假或异常分布，作为一种统计学上的“异常检测”手段。

### 2. 关键文件与功能

| 文件路径 | 功能描述 | 错误/异常处理机制 |
| :--- | :--- | :--- |
| `tools/financial_rigor.py` | 金融数据严谨性验证工具 | **偏差报警**：市值验算偏差 >5% 时输出警告；**安全计算**：使用 `Decimal` 避免精度错误；**输入校验**：CLI 参数类型强制转换。 |
| `tools/report_audit.py` | 研报数据抽检与准出工具 | **准出/打回判决**：随机抽取 15% 数据点与信源比对，若存在 >1% 偏差且无合理解释，则判定为 `FAIL` 并退出码 1，阻止报告发布。 |
| `tools/stock_screener.py` | 动量与价值选股筛 | **空值防护**：在获取价格或基本面数据失败时返回 `None` 并跳过该标的；**网络容错**：使用 `curl` 子进程替代直接 HTTP 请求以规避 SSL 问题。 |
| `tools/xueqiu_scraper.py` | 雪球用户发言爬虫 | **登录态管理**：自动检测登录态过期并触发交互式登录；**断点续爬**：每 10 页保存进度，连续 5 次超时后自动退出并保存现场，防止数据丢失。 |
| `tools/momentum_backtest.py` | 动量回测工具 | **API 降级**：当 Yahoo Finance API 请求失败时，捕获异常并打印 `[WARN]`，继续执行后续逻辑而不中断整个回测。 |

### 3. 架构约定与开发规范

*   **零外部依赖原则**：核心工具仅使用 Python 标准库，减少因依赖冲突或版本不兼容导致的运行时错误。
*   **客观性约束**：在 `CLAUDE.md` 中明确规定，所有分析必须基于事实和数据，严禁主观臆断。这种“认知层面的错误处理”要求所有结论必须有至少两个来源交叉验证。
*   **退出码语义化**：在 `report_audit.py` 中，通过 `sys.exit(0)` 和 `sys.exit(1)` 区分“准出”与“打回”，便于集成到自动化工作流中进行状态判断。
*   **手动干预机制**：对于网络不稳定或反爬严格的场景（如雪球爬虫），采用“交互式登录 + 状态持久化”的方式，将复杂的认证错误处理转化为人工一次性操作。
