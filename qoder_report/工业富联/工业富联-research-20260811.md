**关键观察（与上次对比）**：
1. **毛利率拐点确认**：6.98%（2025）→ 7.35%（26Q1）→ 7.15%（26H1）。**上次报告"毛利率结构性改善"的判断被验证**——高价值 AI 整机柜/液冷/CPO 占比提升 + 规模效应摊薄固定成本。但 **Q2 单季毛利率约 7.0%，环比 Q1 回落 0.35pct**（产品结构或汇率扰动），改善斜率并不陡峭。
2. **净利率 4.25% 创新高**：费用率下降（研发 -1.91%、管理 -1.26%）+ 经营杠杆释放，净利率改善幅度（+0.89pct）大于毛利率（+0.55pct）——**这是"增收增利"质量最高的一个半年报**。
3. **⚠️ 财务费用 +749.91%（19.12 亿）**：汇兑损益变动 + 利息费用增加。人民币波动直接侵蚀利润——这是代工企业汇率敞口的老问题，但本季度幅度异常。
4. **现金流"伪修复"**：H1 经营现金流 73.91 亿（+425%），**但 Q1 单季 250.24 亿、Q2 单季 -176.33 亿**——Q1 集中回款 + Q2 大额备货（Rubin 平台备货启动）的季节性剪刀差。H1 现金转换率 0.31（73.91/237.40），较 2025 全年 0.15 改善，但**离"健康"（0.5+）仍远**。上次报告警示的"利润先行、现金滞后"结构未根本改变。

### 收入漏斗分析（2026H1 更新）

```
[营业收入 5578.61亿]（全球AI服务器ODM约55%份额[高盛]，第一）
   │ - 营业成本约 5179.7亿（GPU占整机成本70%+，付给英伟达/AMD）
[毛利 约398.9亿]（毛利率7.15%）  ← 最惨烈漏损层依然：93%收入归上游
   │ - 研发49.98亿 + 销售6.63亿 + 管理28.61亿 + 财务19.12亿 = 约104.3亿
   │   （财务费用+750%：汇兑+利息，新增漏损）
[利润总额 278.17亿]（+98.37%）
   │ - 所得税（实际税率约14.7%）
[归母净利 237.40亿]（净利率4.25%，历史同期最高）
   │ + 折旧摊销 - 资本开支 - 营运资本占用（Q2备货大额流出：存货1673亿+应收1025亿）
[经营现金流 73.91亿]  ← 现金转换率0.31（Q1 +250亿 / Q2 -176亿）
   │ - 资本开支
[自由现金流 H1约 13.4亿（Q1口径推算）]
```

**漏斗核心结论（较上次的更新）**：
- **漏损结构微变**：毛利层占比不变（93% 付给上游），但**费用层新增"财务费用"这一大漏损项**（+750%，汇兑+利息），挤压了费用率改善的一部分红利。
- **现金转换率 0.31**：较 2025 全年 0.15 翻倍改善，但**Q2 单季 -176 亿**说明改善主要靠回款节奏而非生意质量。Rubin 备货周期下，Q3 现金流仍可能承压。
- 净利率 4.25% 是"薄利 × 巨量周转 × 经营杠杆"共同作用，**依然不是定价权的结果**——与上次结论一致。

**段永平式追问（更新）**：
> **这门生意好在哪？** 依然是那句话：全球没有第二家能以 55% 份额、45 天交付周期承接英伟达 Rubin/GB 系列整机柜代工——规模 + 认证壁垒真实且扩大（ASIC 业务 +3 倍，客户多元化边际改善）。
> **坏在哪？** 毛利率 7.15%、93% 收入付给上游、Q2 现金流单季 -176 亿、财务费用暴增——**它仍然是"给卖铲人组装铲子的人"，只是铲子更贵了**。净利率 4.25% 创纪录，但绝对水平依然微薄。**结论不变：这不是段永平定义的"对的生意"，只是"对的赛道里最大的搬运工"。**
