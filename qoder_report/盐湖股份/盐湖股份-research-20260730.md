## 第一步：数据收集摘要

- **近5年归母净利（亿）**：44.78 → **155.68**(2022峰值) → 79.14 → 46.63 → **84.76**(2025+82%)。强周期。
- **2025分部**：钾产品120.30亿（占营收77.6%、毛利81.4%，毛利率60.71%）；锂产品29.12亿（占18.8%、毛利16.9%，毛利率52.03%）。
- **产能**：氯化钾500万吨/年（国内第一，收五矿盐湖后~530万吨）；碳酸锂原4万吨→2025年9月新4万吨投产→并五矿盐湖后合计~9.8万吨。
- **资源**：察尔汗盐湖3700平方公里独家采矿权，KCl储量占全国97%、LiCl折1049万吨LCE全国第一。
- **成本**：氯化钾单位成本~1200元/吨、碳酸锂完全成本~3.1-3.5万元/吨（全球最左端）。
- **财务**：2025毛利率57.86%、ROE 22.3%、经营现金流101.61亿（/净利1.20倍）、货币资金213亿+、有息负债仅5.98亿。

## 第二步：生意本质分析（段永平"对的生意"）

**一句话本质**：靠中国最大盐湖（察尔汗），卖钾肥（农业刚需、现金牛）+ 盐湖提锂（低成本弹性），"以钾养锂、梯级利用"。

**好生意吗？** 比纯锂矿好得多：
- **钾肥（主业）**：农业刚需（"粮食的粮食"）、进口依存度67%、国产稀缺、资源垄断、毛利率>60%、卤水近零成本——**是一门很好的资源生意**，周期性弱于锂。
- **锂（弹性）**：成本全球最低（"以钾养锂"，尾卤提锂免采矿成本），但价格随周期波动。

**本分**：核心是"守住察尔汗、低成本开采、稳健扩产"。破产重整（2019年亏459亿"A股亏损王"，因盲目上马镁锂钾园等项目）是**严重偏离本分的教训**；五矿入主后回归资源主业、聚焦钾锂，是纠偏。

### 收入漏斗（2025，单位：亿元）

```
察尔汗盐湖资源（氯化钾产490万吨 + 碳酸锂产4.65万吨）+ 钾/锂价格
    │
营业收入 155.01（钾120.30 [77.6%] + 锂29.12 [18.8%] + 其他5.46）
    │ - 营业成本（钾单位成本~1200元/吨、锂~3.06万/吨，均全球最低）
毛利 ~90（综合毛利率57.86%；钾毛利率60.71%贡献81.4%毛利、锂52.03%贡献16.9%）
    │ - 期间费用（管理费用因整合+环保上升）
营业利润
    │ - 税（2025Q4递延所得税资产确认，一次性推高）
归母净利 84.76（净利率54.7%，资源型高利润率）
    │ + 折旧摊销 - 资本开支（4万吨锂盐项目在建工程激增，2025Q3末40.3亿）
经营现金流 101.61（/净利1.20倍，现金质量好）；FCF因扩产低于经营现金流
```

**漏斗核心洞察**：盐湖的利润漏斗质量极高——净利率54.7%、经营现金流/净利1.20倍、营业收现率119%。**最核心优势在"营业成本"这一层**：钾肥1200元/吨、锂3.06万/吨的成本处全球绝对左端，这是资源垄断+梯级利用带来的。**与天齐/多氟多不同，盐湖有钾肥这个弱周期现金牛托底**——压力测试显示，即便碳酸锂跌到4万+钾肥跌到2500元双杀，净利仍约35亿、不亏损。

**段永平式追问**：好在哪？——**好在"一块不可复制的盐湖，同时产出农业刚需的钾和新能源弹性的锂，且都是全球最低成本"**。钾肥提供确定性现金流、锂提供弹性，攻守兼备。这比纯锂矿（天齐）更接近段永平偏好的"有确定性基本盘的生意"。

| 护城河类型 | 强度 | 证据 |
|---|---|---|
| 品牌/定价权 | ★★★ | 钾肥价格随国际大合同，但国产稀缺给一定话语权 |

**护城河趋势**：资源+成本护城河**长期稳固**——察尔汗独家采矿权是"物理+牌照"双重垄断，全国97%钾储量。近期边际变化：①五矿入主带来央企协同（技术、税收、销售套保）；②2025销量-18%、库存+117万吨，反映"量的天花板"（资源保护性开采，藏格已被核减产能为鉴）。

**巴菲特式追问**：10年后护城河还在吗？——**几乎确定在**。察尔汗盐湖不会消失、采矿权独家、成本全球最低。什么能摧毁它？——①钾肥价格长期低迷（俄白复产、老挝/Jansen新增产能2027后）；②生态环保红线限制开采；③资源过度透支致产量递减。但这些影响"利润量"，不影响"护城河存在"。

**空方核心论点**：①强周期，净利156亿→47亿的剧烈波动可能重演，钾肥顶部已现；②销量-18%+累库117万吨，"量"的天花板临近，PE分位56%不便宜；③整合治理不确定，历史巨亏+长期零分红+大额现金不回购，资本配置效率待验证。

## 第六步：行业与文明趋势（李录"文明演进框架"）

- **钾肥**：农业刚需，非"文明级范式转移"而是"永续刚需"——全球人口与粮食安全支撑长期需求，中国进口依存度67%使国产资源具战略价值（保供主题）。
- **锂**：电化学储能文明级趋势，盐湖锂是低成本供给端。
- **价值链位置**：钾肥国内龙头（产能占比>50%）、盐湖提锂成本最低。

**李录式追问**：20年后回看是"标准石油"还是"3Com"？——**更接近"资源型标准石油"**：察尔汗盐湖是不可复制的战略资源，钾肥的农业刚需+锂的能源弹性使其长期价值稳固。它不是昙花一现的概念股，而是"守着一座金山"的资源龙头。关键变量是资本配置——若五矿能提升分红与整合效率，价值会被重估。

## 结论：AI 分析置信度 vs 投资确定性

- **高确定性结论（数据充分）**：察尔汗资源垄断、全球最低成本、钾肥占主导（77.6%营收/81.4%毛利）、PE 13倍主板链最低、负债率14.15%、零分红——扎实。
- **有限信息推理（需谨慎）**：每股自由现金流、PB历史分位、五矿盐湖整合后的协同利润——**数据不足**，相关判断为估算。
- **投资确定性核心变量**：**钾肥价格**（主业，决定利润底）+ **锂价**（弹性）+ **是否重启分红**（估值重估钥匙）。相比其余五家，盐湖是**估值最低、财务最稳、下行保护最好的"资源核心"**——在漏斗组合里，它是比天齐更稳的"资源仓"选择，瑕疵是锂纯度低（钾肥公司）与零分红。

> **风险提示**：本报告为研究分析，非投资建议。盐湖盈利受钾肥与锂价双重周期影响，且长期零分红，数据以2026半年报为准。
