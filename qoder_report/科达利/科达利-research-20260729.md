- **近5年**：营收 44.68→86.54→105.11→120.30→**152.13** 亿（5年CAGR约36%）；归母净利 5.42→9.01→12.02→14.72→**17.64** 亿（连续5年增长，增速由+203%放缓至+20%）。

## 第二步：生意本质分析（段永平"对的生意"）

**一句话本质**：科达利给全球动力/储能电池厂造精密金属结构件（电池壳、盖板、连接件），按件收钱，是电池扩产的"卖铲人"。

**商业模式**：一次性硬件销售（非订阅），但需求随下游电池产量持续再生；重资产制造 + 精密工艺 know-how。收入 96.66% 来自锂电结构件，产品单一、生意纯粹。

**为什么毛利率能稳在 23%+？** 结构件是电池**安全件**（防爆、密封、导电），认证周期 3–5 年，量产后不轻易切换；良品率 ≥99.5%（行业约90%）叠加规模摊薄，二三线企业多在盈亏平衡线，唯科达利稳定盈利。

**经营杠杆**：总费用率约 9.4%（行业最低之一），规模扩张时费用摊薄明显。

### 收入漏斗（2025，单位：亿元）

```
下游电池扩产需求（动力+储能电池产量增长，行业2025装机+40%）
    │ 科达利结构件全球市占率 ~30% / 国内 ~54%
营业收入 152.13
    │ - 营业成本 ~117（原材料铝/钢+人工+制造，占比~77%）
毛利 ~35（毛利率 ~23%）
    │ - 销售/管理/研发费用（研发8.83亿占5.8%）+ 财务费用（含汇兑）
营业利润 ~20（营业利润率 ~13%）
    │ - 所得税（2025Q3子公司补税推高税负）
归母净利 17.64（净利率 11.6%）
    │ + 折旧摊销 - 资本开支（在建项目多，capex偏高）
自由现金流 估约8–10亿（2024口径，2025确切值数据不足）
```

**漏斗核心洞察**：从营收到净利的转化率 ~11.6%，稳定但不高——因为结构件是"制造业加工"生意，加工费每年被下游要求降价。**最核心的竞争优劣势在"营业成本"这一层**：科达利靠规模+良率把单位成本压到低于同业，这是它能在价格战中唯一持续盈利的原因，也是护城河所在。

**段永平式追问**：这门生意好在哪？——**它不赌"谁的电池技术赢、锂价涨不涨"，只赌"电池总量会增长"**。在一个充满周期与技术路线赌博的产业链里，这是最接近"卖水人"的确定性生意。一句话：**卖铲人比淘金者活得久。**

## 第三步：护城河评估（巴菲特"经济护城河"）

| 护城河类型 | 强度 | 证据 |
|---|---|---|
| 品牌/定价权 | ★★☆ | 加工件性质，对下游大厂无提价权，反而每年降价 |
| 转换成本 | ★★★★ | 安全件认证周期 3–5 年，融入客户研发体系，量产后黏性强 |
| 网络效应 | ★☆ | 基本不适用 |
| 规模效应 | ★★★★ | 全球~30%/国内~54%份额，是第二名5倍以上；就近配套摊薄成本 |
| 技术/专利壁垒 | ★★★★ | 精密冲压/拉伸工艺、良率≥99.5%、专利792项 |

**护城河趋势**：过去5年**变宽**——国内份额从约40%升至~54%，二线厂（震裕）虽增长但盈利差。未来5年**取决于技术路线**：CTP/CTC集成化减少单车结构件用量、固态/大圆柱改变形态是主要威胁；科达利已切入特斯拉4680作对冲。

**巴菲特式追问**：10年后护城河还在吗？——**大概率在**。只要电化学电池还在大规模制造，就需要结构件，且认证壁垒使份额向头部集中。**什么能摧毁它？** ①电池彻底去金属壳化（固态电池全固态封装）；②大客户宁德大规模自供或扶持二供。前者是慢变量、后者概率有限（自供不经济）。

## 第四步：逆向思考与风险清单（芒格"反过来想"）

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 加工费长期通缩，毛利率跌破20%且持续 | 中 | 高——ROE缓慢滑坡，估值下修 |
| 大客户宁德（占比32%）份额调整/自供 | 中低 | 高——单一客户冲击 |
| CTP/CTC/固态改变结构件价值量 | 中低 | 中高——需产品转型 |
| 海外扩产（美/匈/泰/马）执行不及+汇兑损失 | 中 | 中 |
| 应收账款高增（2025H1 +50%）致现金流恶化 | 中 | 中 |

**历史类比**：类似"汽车时代卖精密冲压件、电气化时代卖电缆接头"的公司——随行业总量增长、稳健但利润率被下游压制，很难出现暴利，属"稳健寡头"。

**芒格式追问**：聪明人为什么不买/给低估值？——因为它**弹性小**：锂价反转时资源股翻倍，科达利只稳步涨；且加工费通缩是长期逆风，市场担心"增长被降价侵蚀"，所以给了近10年最低PE分位。**我最可能在哪里犯错？** 高估了结构件的"成长性"、低估了加工费通缩的斜率。

**空方核心论点**：①单一客户+单一产品双集中；②加工费长期通缩，毛利率5年从~29%降至~23%；③增速已从+203%降至+20%，海外/机器人新业务未验证。

## 第六步：行业与文明趋势（李录"文明演进框架"）

- **文明级范式转移**：电动化+储能是能源体系从化石→电化学的迁移，**是文明级趋势**，非阶段性热潮。科达利是其中"确定受益、低争议"的配套环节。
- **TAM**：中国锂电结构件 2025 约 570–610 亿 → 2030 约 1190–1291 亿（CAGR ~16%）；全球电池结构件 2032 约 191 亿美元（CAGR ~17.8%）。储能是最强引擎（2026 +56%）。
- **价值链位置**：上游材料波动、下游电池内卷，结构件环节"一超一强多小"，格局最清晰、龙头唯一持续盈利。

**李录式追问**：20年后回看，科达利是"标准石油"还是"3Com"？——更像**电气化时代的稳健配套龙头**：不会是暴利垄断者（下游压价），但会是随行业总量长期增长、份额集中的"隐形冠军"。终局是全球少数几家结构件龙头之一。

## 第七步：估值与安全边际（巴菲特"内在价值"+段永平"对的价格"）

**当前定价**：PE(TTM) ~26.8倍、PB ~3.5倍、PEG ~1.35、股息率~1.45%。**关键锚：PE处近5年<10%、近10年~5.5%历史低分位**，即便公司仍保20%+利润增速——市场已把"加工费通缩+增速放缓"充分定价。

**反向DCF**：当前股价隐含约"未来3年净利年增10–13%+PE维持20倍出头"的预期，属**偏保守定价**。

## 结论：AI 分析置信度 vs 投资确定性

- **基于充分数据的高确定性结论**：格局（一超多小、份额领先）、盈利质量（毛利率稳定、唯一持续盈利）、估值分位（近10年低位）——这些有扎实财报与多源数据支撑。
- **基于有限信息的推理（需谨慎）**：2025全年经营现金流/期末现金、境外收入占比、储能结构件分部收入、每股FCF、EV/EBITDA——**数据不足**，报告中相关判断（如FCF估8–10亿）为估算。
- **投资确定性核心变量**：不在数据多寡，而在**加工费通缩的斜率**与**技术路线（CTP/CTC/固态）对结构件价值量的影响**——这两点决定10年后的ROE中枢，是需持续跟踪的胜负手。

> **风险提示**：本报告为研究分析，非投资建议。数据以2026半年报最新披露为准。
