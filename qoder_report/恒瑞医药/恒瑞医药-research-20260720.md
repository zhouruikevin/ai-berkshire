## 第二步：生意本质分析 — 段永平"对的生意"

### 2.1 一句话定义

**恒瑞是中国规模最大的"创新药研发-生产-销售一体化平台"，商业模式正从"卖仿制药（受集采压制的存量）"切换为"卖创新药（放量的增量）+ 卖管线（BD出海的现金流）"。**

### 2.2 收入结构拆解（2025年）

```
总营收 316.29亿元
├── 药品销售 280.13亿（88.6%）
│   ├── 创新药销售 163.42亿（占药品58.3%，+26.1%）← 增量引擎
│   │   ├── 抗肿瘤 132.40亿（占创新药81%）← 高度集中
│   │   └── 非肿瘤（代谢/自免/呼吸等）31.02亿（+73.4%）← 高增新芽
│   └── 仿制药销售 ~116.7亿（占药品41.7%）← 集采出清后的存量，趋降
├── 对外许可(License-out) 33.92亿（10.7%，+25.6%）← BD现金流，波动大
└── 其他 ~2亿
```

### 2.3 五年盈利能力趋势

**V型反转清晰可见**：2020年营收277亿/净利63亿达峰 → 2021-2022集采冲击"腰斩式"下滑（净利谷底39.06亿）→ 2023起连续3年双增 → 2025营收316亿创历史新高、净利77亿超越2020峰值。**净利增速持续快于营收增速**（2024净利+47%>营收+23%；2025净利+22%>营收+13%），反映高毛利创新药占比提升 + 费用优化（销售费率从2019年36.6%降至2025年28.8%）。

### 2.4 商业模式画布

| 维度 | 恒瑞 | 评价 |
|------|------|------|
| 一次性 vs 复购 | 药品销售=复购（处方粘性）；BD首付款=一次性 | 混合，需拆开看 |
| 硬件 vs 软件 vs 平台 | "研发平台"——管线厚度是核心资产 | 平台型 |
| 毛利率水平 | **86%+**（生物药/创新药驱动） | 极高，同行顶尖 |
| 经营杠杆 | 研发前置投入（87亿/年），创新药一旦放量边际利润率极高 | 高杠杆，向上弹性大 |

### 2.5 收入漏斗分析（2025年，从营收到自由现金流）

```
总营收 316.29亿元
    │ - 营业成本（毛利率86.5%）→ 付给：原料/CDMO/生产
[毛利 约273亿]
    │ - 销售费用 ~91亿（费率28.8%）→ 付给：学术推广/销售团队（近年裁员近4000人）
    │ - 研发费用（费用化）69.61亿 → 付给：临床CRO/研究人员（资本化率20.2%，另17.6亿入无形资产）
    │ - 管理费用 ~20亿
[营业利润 约87亿]
    │ - 所得税等
[归母净利润 77.11亿（净利率24.4%）]
    │ + 折旧摊销/股权激励 - 资本支出（约27亿投资活动净流出）
[经营性现金流净额 112.35亿]（>净利润，含大额BD首付款现金回流+合同负债激增1097%）
    │ 自由现金流（经营现金流-资本开支）约 85亿量级
[自由现金流 ≈ 85亿，FCF/营收约27%]
```

**漏斗核心发现**：
1. **最大漏损在销售费用（91亿）与研发费用（70亿）**——这是恒瑞作为"重研发+重销售"平台药企的宿命。研发费用是"该花的钱"（护城河来源），销售费用则是集采后主动收缩的对象。
2. **经营现金流(112亿) > 净利润(77亿)**，含金量高——2025年含GSK等BD首付款现金回流 + 合同负债同比暴增1097%（预收的BD/销售款）。**但这一现金流的"超额部分"依赖BD节奏，不可线性外推**。
3. **FCF转化率约27%**（自由现金流/营收），在医药制造业中属优秀水平，货币资金409亿、零有息负债——**财务安全性是恒瑞最硬的底牌**。

> **段永平追问**："这门生意好在哪？" —— 好在**86%毛利+零负债+409亿现金+全球第二的管线厚度**，是极少数"输得起"的中国药企（可承受单个管线失败、可持续每年投87亿研发）。差在**创新药收入81%集中于抗肿瘤、海外可见收入不足5%**，全球化程度远逊百济。它是"中国最强的本土创新药平台"，但还不是"全球化药企"。

**生意质量评分：★★★★☆**

## 第三步：护城河评估 — 巴菲特"经济护城河"

| 护城河类型 | 强度 | 证据 |
|-----------|------|------|
| 品牌/定价权 | ★★★☆☆ | 创新药有临床数据支撑的定价权（"双艾"肝癌一线mOS 23.8月登《柳叶刀》），但受医保国谈压制（卡瑞利珠2019入医保降85%）；仿制药无定价权（集采） |
| 转换成本 | ★★★☆☆ | 处方粘性 + 医生使用习惯，但单药可被同靶点竞品替代 |
| 网络效应 | ★★☆☆☆ | 弱。药品无典型网络效应 |
| 规模效应 | ★★★★☆ | 研发规模全球第二（Citeline管线榜，唯一进全球前10的中国药企）；每年87亿研发投入、100+在研管线、400+临床——**中小Biotech无法复制的"广度"** |
| 技术/专利壁垒 | ★★★★☆ | 24款1类创新药获批、多平台（ADC/双抗/GLP-1/PROTAC）；但单靶点技术领先窗口通常仅2-3年，靠"管线组合"而非"单一壁垒" |

### 护城河的本质：不是"单药"，而是"研发工业化能力"

恒瑞真正的护城河**不在任何一款药**，而在于**把研发做成了可持续的工业化流水线**——"上市一批、储备一批、研发一批"的梯队。这解释了为什么它能承受卡瑞利珠单抗被内卷、能承受默克退货PARP1、能承受FDA三次CRL，依然保持增长：**任何单点失败都不致命**。

### 护城河趋势

- **过去5年：变宽**。从"仿制药+少数创新药"到"创新药占比58%、管线全球第二、BD兑现能力全国第一"。
- **未来5年：取决于两件事**——①创新药能否突破"抗肿瘤依赖"（代谢/自免/GLP-1放量）；②能否从"License-out卖管线"升级为"自主全球商业化"（目前海外收入<5%，是最大短板）。

> **巴菲特追问**："10年后这条护城河还在吗？" —— **研发工业化能力大概率还在**（这是组织能力，非单药）。但"全球商业化能力"这条更深的护城河，恒瑞尚未建成——它目前是"把好药卖给MNC去全球卖"，而非"自己卖到全球"。这是它与百济（泽布替尼自主卖到美国74%收入）的本质差距。

**护城河评分：★★★★☆**（本土★★★★★，全球★★★☆☆）

### 4.3 空方核心论点（必须呈现）

1. **"卡在中间"定位质疑**：既无百济的"全球化商业闭环"故事，也无药明的"卖铲子不赌单药"护城河；创新药仍高度依赖抗肿瘤。
2. **BD"卖青苗"忧虑**：把早期管线以低首付、高分成卖给MNC（如默克退货PARP1、Aiolos案例中恒瑞因未持股错失GSK 40倍溢价差价）。
