## 第一章：生意本质分析 — 段永平"对的生意"

### 1.1 一句话定义

**科士达是做数据中心电源设备（UPS为主）起家、拓展到新能源光储充的硬件制造商**，核心能力是电力电子变换和电池管理技术。与盛弘不同的是，科士达在UPS领域有26年中国市场品牌销量第一的积累——这是一个**有品牌积淀+海外ODM双轮驱动**的硬件生意。

UPS生意比充电桩/储能有更好的特点：数据中心客户对电源可靠性极其敏感，品牌认证和渠道建设一旦完成，客户粘性远高于充电桩这种价格敏感型采购。

### 1.2 收入结构（2025年报）

|--------|-------------|------|---------|--------|

| 光储充(储能/光伏逆变器/充电桩) | 20.69 | 39.3% | +52.0% | 19.4% |
| 配套产品 | 1.76 | 3.3% | — | ~33.1% |
| 其他业务 | 0.70 | 1.3% | — | — |
| **合计** | **52.70** | 100% | **+26.7%** | **28.98%** |

### 1.5 收入漏斗分析

```
[2025年：数据中心总出货量(万套) × 均价 + 光储充出货量]
    │
[2025总营收：52.70亿]
    │   数据中心行业（约31.31亿，占59%）
    │   新能源行业（约20.87亿，占39%）
    │ 
    ┌──────────────────────┬─────────────────────┐
    │ 数据中心(UPS) 31.31亿  │ 光储充 20.87亿      │
    │ 直接材料(电力电子/电池)  │ 直接材料(电池/PCS)   │
    │ 约20.5亿                │ 约16.8亿            │
    ├──────────────────────┼─────────────────────┤
    │ 数据中心毛利：10.78亿   │ 光储充毛利：4.00亿    │
    │ 毛利率34.44%            │ 毛利率19.36%        │
    └──────────────────────┴─────────────────────┘
    │ 
[合并毛利：14.78亿（28.98%）]
    │ - 销售费用：约3.5亿（渠道+海外拓展）
    │ - 管理费用：约2.0亿
    │ - 研发费用：约2.5亿（预计占营收~5%）
    │ - 财务费用（净收益）：约-0.5亿（汇兑收益）
[营业利润：约7.3亿（约14%）]
    │ - 所得税+少数股东
[归母净利润：6.11亿（11.7%净利率）]
    │ + 折旧摊销（约0.4亿）- 资本支出（1.91亿）
[自由现金流：7.20亿]  ← FCF/营收转化率 = 13.7%
```

**对比分析**：科士达的FCF转化率（13.7%）低于盛弘（16.7%），主要是因为光储充业务毛利率低且占比较高。但UPS业务本身现金生成能力强劲（2025年OCF 9.11亿为近5年最高），光储充盈亏改善后自由现金流有望进一步提升。

**段永平追问**：这门生意好在哪？
→ **"在一个不会被替代的市场（数据中心电源）做了26年品牌，积累了全球前五的市场地位，现在赶上AIDC建设浪潮。"** 坏处是光储充业务周期性极强（2024年净利腰斩），拉低了整体生意的可预见性。

## 第二章：护城河评估 — 巴菲特"经济护城河"

| 护城河类型 | 评估 | 验证证据 |
|-----------|------|---------|
| 品牌/定价权 | ★★★★☆ | 连续26年中国UPS市场国内品牌销量第一（赛迪顾问），全球前五（Omdia）；高端UPS有品牌溢价，2025年数据中心业务毛利率34.44%保持稳定 |
| 转换成本 | ★★★★☆ | 数据中心UPS一旦部署，后续扩容+维护需要兼容原有系统；关键基础设施"不敢换"的保守心态构成了实质转换成本 |
| 网络效应 | ★☆☆☆☆ | 无（非平台生意） |
| 规模效应 | ★★★★☆ | 50亿+营收体量，在UPS供应链有规模采购优势；国内品牌第一的市占率形成了较好的规模壁垒 |
| 技术/专利壁垒 | ★★★☆☆ | 兆瓦级模块化UPS（效率98%）、800V HVDC、SST等新品布局中，但核心技术并非不可复制 |
| **综合护城河** | **★★★★☆ — 较宽护城河** | **在UPS/数据中心电源赛道护城河显著强于盛弘** |

**护城河趋势**：过去5年护城河**保持稳定**（UPS品牌地位未受冲击）。未来5年，如果AIDC出海成功（北美ODM订单持续增长），海外品牌认可度提升将加宽护城河；但如果华为/维谛在AIDC电源领域拉开代差，护城河可能变窄。

**巴菲特追问**：10年后这条护城河还在吗？
→ **大概率还在**。UPS和数据中心电源不是一个技术迭代极快的行业，客户的核心诉求是"可靠"而不是"最新"——这与巴菲特投资可口可乐的逻辑有相似性：品牌信任一旦建立，很难被替代。最大威胁是：①AIDC架构变革（如数据中心从集中式UPS到分布式HVDC）可能颠覆传统UPS的市场；②华为的全面竞争（华为已是UPS中国市场整体份额第一）。

## 第三章：逆向思考与风险清单 — 芒格"反过来想"

### 3.1 失败路径

| 失败路径 | 概率 | 影响程度 | 信号指标 |
|---------|------|---------|---------|
| 户储/光伏去库再次发生 | 中 | 高（光储充收入占39%，毛利率仅19%） | 海外储能订单增速放缓/毛利率进一步下滑 |
| 北美AIDC订单不及预期 | 中 | 中高（核心增长叙事，但尚未验证持续大单） | 2026H1中报相关订单披露低于预期 |
| 应收账款坏账 | 中低 | 中（15.9亿应收占净利2.6倍，1年以上6.09亿） | 应收账款周转天数持续恶化/单项计提增加 |
| 人民币升值持续 | 中高 | 中（海外收入52%+，2026Q1财务费用已转正） | USD/CNY汇率趋势，2026Q1已出现汇兑损失 |
| 控股股东继续减持 | 中低 | 中低（实控人控制59%，小幅减持不影响控制权） | 减持公告继续发布 |
| AIDC技术路线变革（HVDC替代UPS） | 中 | 高（长期颠覆UPS核心业务） | 数据中心新建项目HVDC采用率提升 |

### 3.2 空方核心论点

1. **利润周期性极强**：2023年8.45亿→2024年3.94亿（-53%）→2025年6.11亿（+55%），这种波动意味着"正常化盈利"难以定义。当前2026E PE 22x基于9.03亿一致预期，一旦再次去库，PE会瞬间跳升至40x+。
2. **应收账款高企**：15.9亿（2025末）约为年归母净利的2.6倍，1年以上账龄6.09亿，光伏行业回款周期长是顽疾。
3. **毛利率中枢下移**：从31-32%降至29%，光储充占比持续提升（毛利率仅19%）将进一步拉低整体毛利率。
4. **减持记录**：控股股东2022年减持约5.64亿、2026年再减持约582万股（约2亿+），虽然不影响控制权，但"减持套现"的时机选择值得思考。

### 3.3 历史类比

科士达的"数据中心稳定现金牛+新能源周期弹性"模式，与**伊顿（Eaton）**有一定相似性——UPS业务提供下限，新能源业务提供弹性。但科士达的问题是新能源业务占比过高（39%），导致整体利润波动远大于伊顿（其电气业务占比~70%且增长稳定）。

### 3.4 芒格式追问

**我最可能在哪里犯错？**
→ 最可能犯错的地方是**低估了周期破坏力**。2024年户储去库导致净利-53%，2026年如果再次发生同类事件，当前22倍PE的买入价会变得很贵。聪明人不买/做空科士达的理由可能是：AIDC叙事已被充分priced in，而周期风险仍被低估。

### 4.2 资本配置能力

- **研发投入**：预计约2.5亿（~5%营收），兆瓦级UPS、800V HVDC、LiquiX液冷等新品有序推进
- **并购/合资**：与宁德时代的合资（时代科士达）被证明是战略正确的——借助宁德品牌和供应链进入储能，2021年受让控股权后在户储爆发期充分受益（即使2024年经历去库）
- **分红**：上市以来累计分红9.42亿，2025年10派4.5元，2026中期10派3.3元
- **融资**：上市后再融资记录少（2023年向特定对象发行预案未落地），扩张靠自有资金——这是财务纪律稳健的信号

### 4.3 股东利益一致性

- 实控人刘程宇/刘玲夫妇通过宁波科士达创投合计控制约59.4%——**高度控股**，但也意味着减持对市场的负面影响较大
- 控股股东2022年减持约5.64亿、2026年减持约2亿+，累计套现约7.6亿
- 高管薪酬合理（人均约90万），无过度激励
- 2026年中期分红强度提升（10派3.3元），显示股东回报意识增强

**段永平追问**：如果CEO退休，还能保持竞争力吗？
→ 刘程宇已63岁，但公司有相对稳定的管理层梯队（沈文轶等事业部负责人）。关键在于科士达的竞争壁垒更多建立在品牌和渠道上（组织能力），而非创始人个人能力——所以CEO退休的影响可能小于盛弘。
