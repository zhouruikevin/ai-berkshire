## 🔴 开篇必读：三个必须先纠正的事实

在进入产业分析前，有三个流传中的说法与可核实事实不符。不先纠正，后面所有推理都会偏。

### 纠正一：引爆本轮行情的两条新闻，属于**两条不同的产业链**

本研究的触发新闻是《中际旭创拟入股中石科技 吴氏家族一把套现逾17亿》。但这条新闻讲的是**光模块的器件材料散热**（VC均热板、导热石墨），**不是数据中心液冷**。

同日液冷板块集体涨停，真正的驱动事件是**另一件事**——液冷国家标准 GB/T 48023-2026 获批发布。

> **两件事同一天，市场把它们当成一件事在炒。** 一条是"某公司被光模块龙头入股"，一条是"液冷行业有了国标"。受益公司名单重叠度很低。混着理解就会买错标的。

### 纠正二："转让价对市价折价17%"是**错误的参照系**

| 参照 | 数值 | 折价/溢价 |
|---|---|---|
| 转让价 | 55.70 元/股 | — |
| **8/13 收盘价（签约当日）** | **56.13 元** | **折价 0.77%** ← 正确参照系 |
| 8/14 收盘价（涨停后） | 67.36 元 | 折价 17.31% ← 常见的错误参照系 |

**事实**：协议是 8/13 晚签署的，当时市价 56.13 元，转让价 55.70 元，**几乎是平价成交（折价不足 1%）**。

8/14 股价涨停 20.01% 到 67.36 元，是市场对这条公告的**反应结果**，不是交易条件。用涨停后的价格去算"折价17%"，等于用结果倒推条件，会得出"旭创低价拿到便宜筹码/大股东贱卖"的错误结论。

**正确的推论是**：中际旭创基本按市价接盘，浮盈 (67.36−55.70)×3137.25万股 ≈ **3.66 亿元**，但这是市场情绪给的，不是谈判能力给的。

### 纠正三：三条广泛流传的"政策硬指标"，**未找到官方依据**

| 流传说法 | 核查结果 |
|---|---|
| "2026年底新建大型数据中心液冷渗透率需达标60%以上" | ❌ **未找到官方依据**。仅见于展会宣传页（深圳液冷展），无部委文件、无国标、无地方政府原文 |
| "PUE严控1.15以内" | ❌ **未找到官方依据**。现行强制国标 GB 40879-2021 的限定值是 **PUE≤1.50**；最严的地方要求是北京核心区 1.2、上海智算中心 1.25 |
| "北上广深已明确禁止新建纯风冷数据中心" | ❌ **未找到官方依据**。查到的地方政策用的是差别电价、补贴、"原则上"等**经济激励与弹性措辞**，没有一条写"禁止" |

这三条如果当真，会显著高估液冷的政策强制性。真实的政策约束比传言弱得多（详见 §4.2）。

## 一、事件锚点：两条新闻的可核实事实

### 1.1 事件A：中际旭创受让中石科技 10.47% 股权（器件材料链）

**交易结构（事实，来源：中石科技/中际旭创公告，经第一财经、财联社、每日经济新闻、格隆汇、北京商报交叉核对）**

| 项目 | 内容 |
|---|---|
| 签署时间 | 2026-08-13 晚间《股份转让协议》 |
| 受让方 | 中际旭创（300308.SZ） |
| 转让方 | 中石科技控股股东 吴晓宁、叶露、HAN WU（吴憾）三人 |
| 股份数量 | 31,372,504 股（3137.25万股，无限售条件流通股） |
| 占总股本 | **10.47%** |
| 转让价格 | **55.70 元/股** |
| 交易总价 | **1,747,448,473 元（17.47 亿元）** |
| 付款安排 | 分两期各约 8.74 亿元：第一期在中石科技披露公告后 10 个工作日内；第二期在收到中登深圳分公司《证券过户登记确认书》后 10 个工作日内 |
| 终止条款 | 签署后 60 个交易日内因转让方或上市公司原因未完成过户，受让方可终止并要求退款 |
| 交易后持股 | 转让方由 125,490,015 股（**41.90%**）降至 94,117,511 股（**31.42%**），**仍为控股股东、实际控制人** |
| 旭创地位 | 成为**第三大股东**及 5% 以上股东 |
| 性质认定 | 不构成关联交易、不构成重大资产重组、不触及要约收购 |
| 审批 | 需深交所合规性审核 |

**总股本校验**：125,490,015 ÷ 41.90% ≈ 299,499,081 股（约 2.995 亿股）；3137.25万 ÷ 2.995亿 = **10.47%** ✅ 与公告一致。
**市值校验**：67.36 元 × 2.995 亿股 = **201.72 亿元**，与行情工具显示的 201.75 亿元偏差 0.01% ✅

**四条最容易被忽略、但决定性质的事实**：

1. **公告明确写明"双方不存在股价对赌、股份代持、保底保收益等利益分割安排或者补充协议"** —— 也就是说，**没有订单绑定、没有业绩承诺、没有采购保底**。
2. **这是从实控人家族手里受让老股，不是定增** —— **17.47 亿元全部进入吴氏家族口袋，一分钱不进上市公司**。中石科技不因此增加一分钱研发或扩产资金。
3. **公告未披露中际旭创将参与经营管理**（未提董事席位安排）。
4. **17.47 亿元占中际旭创市值（11030.60 亿元）的 0.158%** —— 对旭创而言这是一笔零头级别的财务/战略投资，其决策重要性远低于市场解读的"深度绑定"。

**中际旭创给出的理由（观点，非事实）**："未来随着公司800G、1.6T等高端光模块产品的持续放量，功耗密度持续提升，散热需求呈现显著增量，预计将与公司业务产生较强的协同效应。"

**中石科技（300684.SZ）是谁**：北京中石伟业科技股份有限公司，1997 年成立。产品覆盖高导热石墨、导热界面材料（TIM，深耕近20年）、热管、VC均热板、液冷模组。**已并表"中石讯冷"，补齐冷板、流道设计及液冷模组能力，液冷产品已实现批量交付** —— 因此它实际上**同时横跨两条链**。光模块 VC 模组已通过国内外头部客户认证并供货。客户包括北美消费电子大客户、三星、华为、中兴、爱立信、诺基亚。

### 1.2 事件B：GB/T 48023-2026 液冷国标获批（液冷系统链）

**事实（来源：2026年第33号中华人民共和国国家标准公告、中国电子技术标准化研究院 cesi.cn、经济日报、中科曙光官网）**

| 项目 | 内容 |
|---|---|
| 标准号 | **GB/T 48023-2026** |
| 名称 | 《数据中心冷板式液冷系统技术规范》 |
| 地位 | **我国首部数据中心液冷国家标准** |
| 性质 | **GB/T = 推荐性标准**（不是强制性 GB） |
| 立项 | 2024年7月 |
| 发布 | 2026年7—8月 |
| **实施日** | **2027-02-01** |
| 归口 | 中国电子技术标准化研究院（CESI），全国信标委信息技术与可持续发展分委会 SAC/TC 28/SC 39 |
| **主编单位** | **曙光数创**（中科曙光旗下，920808.BJ 北交所） |
| 覆盖范围 | 系统设计、部件要求、水力计算、测试验证、部署运维全流程；**冷板组件、快速接头、冷量分配单元（CDU）均纳入统一规范** |

**曙光数创的先动位置（事实）**：2011 年率先提出液冷技术路线；产品线含 C7000 冷板液冷、C7000 2.0 风液混冷、C7000-F 相变间接液冷、C8000 浸没相变液冷；覆盖数十 kW 到逼近 1MW 机柜；已牵头或参与 **5 项国标、3 项地标、7 项行标、20 余项团标**。

> **注意标准性质**：GB/T 是**推荐性**标准，不具强制执行力。它的作用是统一接口与测试口径、降低采购方验证成本，而非"不合规不许卖"。把 GB/T 当成强制门槛，是本轮叙事里第二个容易犯的错。
