# qoder_report — 新分析产出目录

自 2026-07-03 起，Qoder（及 Claude Code / Codex）生成的**新投研报告**统一输出到本目录，
目录结构与命名沿用原 `reports/` 规范（按公司名建子目录等）。

- 原 `reports/` 为**历史归档**：只读、不改动。
- 持续维护型"活文件"仍在 `reports/` 就地维护（避免历史断裂）：
  - 组合文件 `reports/portfolio-latest.md`
  - 投资论文 `reports/{公司名}-thesis.md`
  - 瓶颈地图 `reports/bottleneck-map/`
- 读取历史样本/旧数据时仍指向 `reports/`。
