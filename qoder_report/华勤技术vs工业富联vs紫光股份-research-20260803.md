1. **代工模式的"高ROE陷阱"**：工业富联ROE 21.65%很亮眼，但毛利率仅7%、经营现金流/净利仅0.15、自由现金流为负——高ROE是高周转+高杠杆堆的，不是高质量盈利。

## 2. 生意本质分析 — 段永平"对的生意"

### 2.1 一句话定义

- **工业富联**：给全球AI军备竞赛"造机柜"——英伟达GB200/GB300 NVL整机柜的全球最大代工厂，本质是**"垂直整合的超大规模代工"**，用天量周转把7%毛利做成21%的ROE。
- **华勤技术**：给所有品牌"贴牌造电子产品"——从手机到AI服务器的全品类ODM，本质是**"平台化研发+规模代工"**，一次开发多客户复用，靠品类扩张换增长。
- **紫光股份**：给中国政企"卖ICT整套装备"——新华三的服务器+网络+存储+云全栈品牌，本质是**"自有品牌+渠道+信创准入"的系统集成商**，靠网络设备护城河和国产化红利。

**三种模式的本质排序（毛利率验证）**：品牌ICT（紫光14.59%）> ODM（华勤7.7%）≈ 代工（工业富联7%）。**品牌 > 代工，这是商业模式的铁律。** 但紫光的品牌溢价被分销业务和少数股东稀释到了归母层面。

**漏斗对比的三个决定性洞察**：
1. **毛利率环节**：紫光品牌模式14.59% > 华勤/工业富联代工模式7% ——**这是三者商业模式高下的根本分野**。但紫光的品牌优势在归母层面被稀释。
2. **现金流环节（最关键）**：**紫光OCF/净利2.07（最健康）> 工业富联0.15 > 华勤-0.05（转负）**。这与市场直觉相反——市场追捧的两个"AI代工成长股"（工业富联、华勤）现金流质量最差，被冷落的紫光反而现金流最实。**代工模式的高增长是用营运资本和债务堆的。**
3. **少数股东/利息环节**：紫光归母16.86亿 vs 新华三本身31.51亿，一半利润漏给了少数股东和并购利息——但这一层"漏损"会随2026年并表提升而收窄。

### 2.4 段永平式追问："这门生意好在哪？"

- **工业富联**：好在"全球AI军备竞赛谁赢它都赚，且垂直整合别人抢不走"。反面：**它的护城河宽度由母公司鸿海决定**（鸿海体系内无人竞争这块），不是自主规划的；7%毛利意味着**没有定价权**，只是英伟达和CSP的"手臂"。
- **华勤技术**：好在"平台化研发一次开发多客户复用，品类可无限扩张"。反面：**"高流水低毛利"的夹心饼干**——上游芯片/屏幕定价，下游品牌压价，前五大客户中4家同时是供应商（买卖模式），毫无议价权，且增长已透支现金流。
- **紫光股份**：好在"自有品牌+网络设备护城河+信创准入，毛利率最高"。反面：**归母净利被结构性压制**，且高度依赖政企/信创政策，海外供应链（博通交换芯片）有断供风险。

**段永平的共同追问**：这三门生意，有哪一个能在"股市关闭5年"后让你安心？**代工（工业富联/华勤）本质是没有定价权的规模生意，护城河是"客户懒得换+规模成本"，脆弱于AI capex周期；品牌（紫光）有护城河但被财务结构拖累。** 段永平大概率对三者都会说"看不太懂，或者不够便宜"。

## 3. 护城河评估 — 巴菲特"经济护城河"

| 护城河类型 | 工业富联 | 华勤技术 | 紫光股份 |
|-----------|---------|---------|---------|
| **技术/专利壁垒** | ★★★★☆ 液冷/机柜级整合/800G，GB200代工~50% | ★★★☆☆ 平台化研发、X86+ARM双架构、1.7万研发 | ★★★★☆ 新华三网络设备/交换机/自研芯片(51.2T CPO) |
| **转换成本** | ★★★☆☆ 认证+交付绑定，但CSP可多供 | ★★☆☆☆ ODM可替换性较高 | ★★★★☆ 政企ICT整套部署，切换成本高 |
| **规模效应** | ★★★★★ 9000亿营收，全球代工龙头 | ★★★★☆ 全球最大消费电子ODM 22.5% | ★★★☆☆ 967亿，国内ICT龙头之一 |
| **网络效应** | ☆ 无 | ☆ 无 | ★☆ 弱（生态适配） |
| **品牌/定价权** | ★☆☆☆☆ 代工无定价权（毛利7%） | ★☆☆☆☆ ODM无定价权（毛利7.7%） | ★★★☆☆ H3C品牌+信创准入，毛利14.59% |

### 3.1 护城河来源与趋势

- **工业富联**：护城河=**规模+垂直整合+英伟达绑定**，宽但"租来的"（份额由鸿海分工+英伟达关系决定）。趋势：AI景气期变宽（GB300、液冷价值量提升），但**一旦英伟达调整代工份额或AI capex见顶即收窄**。
- **华勤技术**：护城河=**平台化研发+多品类规模**，中等且**在被增长稀释**（综合毛利率从9.6%降至7.7%）。趋势：向AI服务器/汽车/机器人扩张，但每进一个新领域都是低毛利红海，护城河"广而浅"。
- **紫光股份**：护城河=**新华三的网络设备市占（企业网交换机36.1%第一）+政企客户+信创准入**，最"真实"且**在变宽**（2026内资化打开涉密/军工/央企信创市场）。趋势：信创+国产算力利好，护城河向上。

### 3.2 巴菲特式追问："10年后护城河还在吗？什么能摧毁它？"

- **工业富联**：摧毁者=AI capex反转、英伟达自建/转移代工、CSP自研ASIC绕过（谷歌/亚马逊ASIC 2026H2放量）、母公司关联交易侵蚀小股东。
- **华勤技术**：摧毁者=手机需求持续疲软、大客户流失、AI服务器代工被工业富联/台系碾压、现金流危机（债务75%+经营现金流转负若持续）。
- **紫光股份**：摧毁者=华为在网络/服务器全面碾压、博通等海外交换芯片断供、高杠杆(81.85%)+140亿商誉减值、信创政策不及预期。**但紫光的护城河是三者中"最不易被AI周期摧毁"的**（政企ICT需求相对刚性+信创长逻辑）。

## 4. 逆向思考与风险清单 — 芒格"反过来想"

### 4.1 "这三家可能失败的路径"

### 4.2 历史类比

- **工业富联/华勤 ≈ 2000年互联网泡沫的思科代工商（旭电/伟创力）**：景气顶点营收爆发、估值高企，但代工本质决定了周期反转时利润和估值双杀。**台系可比公司广达/纬创当前PE仅12-15x**——A股工业富联31x、华勤27.6x相对台系有2倍溢价，这个溢价靠A股流动性和成长预期支撑，脆弱。
- **紫光/新华三 ≈ 中国版的HPE/Cisco（品牌ICT）**：有真实护城河但增长温和，估值靠信创+资产重估叙事。
