## 3. 分公司解读

### 美团（影响最显著，但仍是"题材级"）
- @500元持股 **175.6亿**，相当于**归母净资产的 9.5%**、市值的 3.2%。这是4家里唯一"看得见"的量级。
- 但：① 相对其数千亿市值仍是**个位数%**；② 2025年主业陷外卖补贴战、预计亏损，一笔一次性投资浮盈**无法改变经营基本面**；③ **有锁定期**（Pre-IPO股东普遍限售12个月），账面浮盈不可即时兑现。

### 小米（次之，量级已不重要）
- @500元持股 **80.4亿**，占市值 0.83%、净资产 2.8%。对一家 2025 年归母利润奔向 450亿、市值近万亿的公司，**属情绪催化，非价值驱动**。

### 中国太保 / 新华保险（可忽略）
- 穿透后实际权益仅 **5.34亿 / 1.93亿**，占各自市值、净资产均**不足 0.2%**，相当于年度净利的 **0.9% / 0.4%**。
- 即便宇树股价再翻倍到 1000元，太保/新华的持股也不过 10.7亿 / 3.9亿，**对报表仍无实质意义**。这是典型的"险资重仓硬科技"**叙事标的**，而非业绩标的。

## 4. 【关键】会计计量：浮盈≠净利润增厚

**这是本测算最容易被误读的地方**——上表"≈年度净利 X%"不等于"增厚净利润 X%"，能否进利润表取决于会计分类：

| 计量方式 | 公允价值变动去向 | 是否影响净利润 |
|---|---|---|
| FVTPL（以公允价值计量且变动计入损益） | 投资收益 → 利润表 | **是** |
| FVOCI（指定为其他综合收益） | 其他综合收益 → 净资产，不结转损益 | **否**（只影响净资产） |
| 权益法（重大影响，通常≥20%） | 按持股比例确认投资损益 | 是 |

- **美团/小米**：对宇树持股均 <20%、无重大影响，属**金融资产**。分类为 FVTPL 还是 FVOCI **取决于各公司会计政策，需查财报附注**——本报告无法确定。若为 FVOCI，则 500元带来的百亿浮盈**只增厚净资产、不进利润表**。
- **太保/新华**：经 PE 基金 LP 持有，基金份额通常按 **FVTPL** 计量，公允价值变动进投资收益（影响净利润），但金额极小（亿元级）。
- **共同约束**：Pre-IPO 持股有**锁定期**，且未上市阶段公允价值可能按成本/最近融资估值计量，**上市后才锚定市价**——"@500元"的账面浮盈需待宇树实际上市且价格站上500元后才成立。
