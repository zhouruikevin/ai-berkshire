## 第一章：生意本质分析 — 段永平"对的生意"

### 1.1 一句话定义

**盛弘股份是做电力电子硬件设备的制造商**，将电力变换技术（AC/DC、DC/AC）产品化，卖给充电桩运营商、储能集成商、数据中心和工厂，从中赚取制造利润和部分品牌溢价。

这不是平台生意，不是订阅生意，不是网络效应生意——这是**规模效应驱动的硬件制造生意**，毛利率取决于产品差异化和规模带来的成本优势。

|--------|-------------|------|------|--------|----------------|------|------|--------|

### 1.5 收入漏斗分析

```
[顶层：电力电子设备市场潜在需求]
    │
[2025年总营收：34.63亿]
    │ - 充电桩直接材料（IGBT/电容/结构件等）：约9.72亿（估算）
    │ - 储能直接材料（电池模组/PCS元器件）：约5.95亿
    │ - 电源直接材料（功率器件/PCB/散热件）：约2.94亿
[毛利：13.32亿（38.5%）]
    │ - 研发费用：约2.4亿（占比17.8%营收，较高）
    │ - 销售费用：约2.3亿（渠道+海外拓展）
    │ - 管理费用：约1.8亿
    │ - 财务费用/汇兑：约0.2亿（2026H1激增）
[营业利润：约5.0亿（14.4%）]
    │ - 所得税（约15%）：约0.75亿
    │ - 少数股东损益：略
[归母净利润：4.76亿（13.7%净利率）]
    │ + 折旧/摊销（非现金）：约0.4亿
    │ - 资本支出：约1.24亿（购建固定资产）
[自由现金流：5.77亿]  ← 漏斗末端转化率 ≈ 自由现金流/营收 = 16.7%
```

**对比同行**：盛弘的毛利率（38.5%）低于工业富联/AIDC电源公司，但高于纯充电桩模块厂商。FCF/营收转化率16.7%在同体量硬件公司中处于较好水平，主要受益于2025年经营现金流大幅改善。

**段永平追问**：这门生意好在哪？一句话——**"在电力电子需求爆发的年代，做多赛道硬件布局来捕捉增长"，但坏处是每个赛道都有更强大的竞争对手（充电桩看华为/英飞源，储能看阳光电源/科华，AIDC看华为/维谛），盛弘在每个赛道都非龙头。**

## 第二章：护城河评估 — 巴菲特"经济护城河"

| 护城河类型 | 评估 | 验证证据 |
|-----------|------|---------|
| 品牌/定价权 | ★★☆☆☆ | 充电设备毛利率持续下滑（2021年38.2%→2026H1 30.4%），定价权弱；2026年7月宣布提价10-30%，能否执行到位需观察 |
| 转换成本 | ★★★☆☆ | 客户认证周期（海外尤为漫长）+ 适配测试存在一定转换成本，但硬件标准品切换成本有限 |
| 网络效应 | ★☆☆☆☆ | 无（硬件制造商，用户增加不改善产品价值） |
| 规模效应 | ★★★☆☆ | 10亿级营收体量在充电桩/储能领域已形成一定规模采购优势，但与华为/阳光电源不在同一量级 |
| 技术/专利壁垒 | ★★★☆☆ | 电力电子技术积累15年+，储能PCS国内/海外均排第4，但技术领先并非代际级 |
| **综合护城河** | **★★☆☆☆ — 窄护城河** | |

**护城河趋势**：过去5年充电桩竞争加剧，毛利率从43.5%降至38.5%，护城河在**变窄**。未来5年若AIDC电能质量业务占比提升（毛利率>58%），可能局部改善，但充电桩赛道价格战大概率持续。

**巴菲特追问**：10年后这条护城河还在吗？
→ 盛弘在充电桩赛道面对华为、英飞源等强敌，在储能PCS面对阳光电源、科华。10年后如果不能在任一赛道做到前三，护城河可能消失。最大威胁是华为（品牌+技术+渠道碾压）和英飞源（充电模块专精）。马来西亚/美国本地化产能和海外渠道可能是未来最持久的差异化来源。

## 第三章：逆向思考与风险清单 — 芒格"反过来想"

### 3.1 失败路径

| 失败路径 | 概率 | 影响程度 | 信号指标 |
|---------|------|---------|---------|
| 充电桩价格战进一步恶化，毛利率跌破25% | 中高 | 高（营收占比43%） | 充电设备毛利率继续下滑 |
| 储能出海受关税/政策壁垒冲击 | 中 | 高（储能占比24%，且海外是关键增量） | 储能收入增速再次转负 |
| 应收账款坏账暴雷 | 中低 | 中高（10.43亿，占年化营收30%） | 应收账款周转天数恶化/单项计提增加 |
| 核心管理层/技术人员流失 | 低 | 高（创始人兼总经理方兴连续减持） | 继续减持/高管离职 |
| AIDC新业务（HVDC/SST）研发失败或错过窗口 | 中 | 中（当前零收入，失败不影响生存） | 研发进展不及预期 |
| 原材料涨价无法完全传导 | 中 | 中（提价10-30%面临客户流失） | 提价后订单增速放缓 |

### 3.2 空方核心论点

1. **股东持续减持**：创始人方兴2025年减持约100万股后，2026年5月再次披露减持计划（合计586万股），联合创始人肖学礼清仓式退出。创始人持续减持是最大信心缺失信号。
2. **毛利率趋势性下行**：从2021年43.5%到2025年38.5%，充电设备毛利率从38%降至30%。2026年7月虽宣布提价10-30%，但在竞争激烈的充电桩市场，提价能否推进存疑。
3. **每赛道均非龙头**：充电整桩二线、储能PCS第四、充电模块非头部——在华为、阳光电源等巨头夹击下，长期份额被侵蚀风险大。
4. **应收账款持续攀升**：从2021年3.79亿增至2026H1末10.43亿，占年化营收约30%，占净资产的约50%。

### 3.3 芒格式追问

**我最可能在哪里犯错？**
→ 太关注电动车/储能/AIDC的行业增速（这些确实在快速增长），但忽略了**盛弘在每个赛道都不是第一选择**。行业涨50%不代表盛弘能涨50%。聪明人不买盛弘的理由可能是：既然买充电桩为什么不买华为/特来电？买储能为什么不买阳光电源？买电能质量为什么不直接买？
