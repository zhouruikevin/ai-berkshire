## 2. 生意本质分析 — 段永平"对的生意"

### 2.1 一句话定义生意本质

- **中微公司**：卖"芯片制造最核心的一把刻刀"——高端等离子体刻蚀设备的国产龙头，靠单点技术纵深切入全球寡头垄断的刻蚀赛道，并向薄膜等品类外延。
- **北方华创**：做"国产半导体设备的沃尔玛/应用材料"——用最全的工艺装备品类（刻蚀/薄膜/热处理/清洗/离子注入/涂胶显影）绑定晶圆厂，靠平台化广度+整线供应能力吃国产替代的总量红利。

**一个是"深"，一个是"广"**——这是理解两家一切差异的原点。

### 2.2 收入结构拆解

**中微公司（2025，来源：新浪财经年报解读2026-03-30）**：

| 产品线 | 收入 | 同比 | 占比 |
|--------|------|------|------|
| 刻蚀设备（CCP+ICP） | 98.32亿 | +35.12% | **79.4%** |
| 薄膜设备（LPCVD+ALD） | 5.06亿 | **+224.23%** | 4% |
| MOCVD/备品备件/其他 | ~20亿 | — | ~16% |

- 高度聚焦刻蚀（近八成）；薄膜为爆发中的第二曲线（基数小）。
- 区域：大陆占比升至97.37%，**台湾地区营收-31.63%、海外-21.59%**——海外敞口收缩（地缘+国产替代反向效应）。

**北方华创（2025，来源：新浪/蓝鲸2026-04-17）**：

| 板块 | 收入 | 同比 | 占比 | 毛利率 |

- 电子工艺装备内部：**刻蚀突破100亿 + 薄膜沉积突破100亿**（两者约占总营收70%）+热处理>10亿+湿法>5亿+离子注入（2025新突破）+涂胶显影（收购芯源微补齐）。

### 2.3 收入漏斗对比（顶层业务量 → 自由现金流）

半导体设备的顶层指标为**设备出货金额（≈营收）**，向下漏损结构如下（2025年）：

```
中微公司                                北方华创
营收 123.85亿                           营收 393.53亿
  │ 毛利率 39.17%                         │ 毛利率 40.10%
毛利 ~48.5亿                            毛利 ~157.8亿
  │ -研发费用化24.75亿(占营收20%!)         │ -研发费用化54.35亿(+47%)
  │ -销售/管理费用                        │ -销售费用16.36亿(+48.6%) -存货跌价14.33亿
营业利润                                营业利润(Q4断崖)
  │ +非经常损益5.62亿(占净利26.62%)        │ +政府补助等
归母净利 21.11亿                         归母净利 55.22亿(-1.77%)
  │ 其中扣非仅15.50亿                      │ 其中扣非53.36亿
经营现金流 22.95亿(OCF/净利1.09)         经营现金流 21.33亿(OCF/净利仅0.39)
```

**漏斗对比的关键洞察**：
1. **中微的"漏损"漏在研发**（费用化20%+资本化）——主动深蹲，且**现金流质量好**（OCF/净利1.09，经营现金流甚至高于净利润）。
2. **北方华创的"漏损"漏在多处**——毛利率下滑+研发+存货跌价14.33亿+芯源微低毛利并表，且**现金流质量差**（OCF/净利仅0.39，每赚1元利润不到4毛变现金）。
3. **最核心差异环节**：**现金转化能力**。中微的利润更"实"（现金流覆盖），但归母净利含非经常损益水分（扣非才15.5亿）；北方华创利润"账面大但变现弱"，营运资本占用重（存货286亿、周转>400天）。

### 2.4 段永平式追问："这门生意好在哪？"

- **中微**：好在"高端刻蚀是芯片制造绕不过的核心工序，且全球只有3-4家能做，中微是唯一进入台积电先进制程的中国刻蚀厂"。若一句话——**"卡在咽喉位置的一把刀"**。
- **北方华创**：好在"客户要建一条产线，能一次性从它这里买到最多品类的设备，替代成本和协同价值高"。若一句话——**"国产设备的一站式超市"**。
- **段永平会追问的反面**：这两门生意的"好"都建立在**"国产替代"这个政策+地缘驱动的窗口**上，而非纯粹的自由市场竞争力。全球龙头毛利率48-52%，两家仅~40%——说明在**没有保护的公平竞争中，两家的产品溢价能力仍弱于AMAT/LAM/TEL**。生意的"好"有多少来自本事、多少来自"别人被禁售"，是必须诚实面对的问题。

## 3. 护城河评估 — 巴菲特"经济护城河"

| 护城河类型 | 中微公司 | 北方华创 |
|-----------|---------|---------|
| **技术/专利壁垒** | ★★★★☆ 高端介质刻蚀(CCP)全球第3-4；5nm进台积电；深宽比60:1量产、攻关100:1；累计专利3300+；零部件称基本100%自主 | ★★★☆☆ 平台广度对标AMAT；专利超9900件(行业第一)；但**单赛道深度落后**，先进制程多为28nm级，核心零部件自主率仅50-55% |
| **转换成本** | ★★★★☆ 刻蚀设备认证周期长、价值量高，导入后强黏性 | ★★★★☆ 多品类整线绑定，切换成本更高（一站式锁定） |
| **规模效应** | ★★☆☆☆ 体量小(124亿)，规模摊薄有限 | ★★★★☆ 393亿营收+品类协同，规模显著领先 |
| **网络效应** | ☆ 基本无 | ☆ 基本无 |
| **品牌/定价权** | ★★★☆☆ 高端刻蚀有一定定价权，但毛利率仍降至39% | ★★☆☆☆ 平台化摊薄，毛利率40%且下滑，定价权弱 |

### 3.1 护城河来源的本质差异（核心结论）

- **中微的护城河是"窄而深"的技术壁垒**：来自高端刻蚀单点的全球稀缺性（能做5nm介质刻蚀的公司全球屈指可数）。**风险**：护城河宽度依赖单一品类，平台化扩张进入的CVD/薄膜赛道，中微是追随者（薄膜仅5亿 vs 北方华创100亿+，vs 拓荆更专业）。
- **北方华创的护城河是"宽而浅"的平台广度**：来自品类最全+客户整线绑定+国资背书。**风险**：广度换来的是每个单品都不是绝对最强（刻蚀不如中微高端、CVD不如拓荆、清洗不如盛美），"样样通样样松"，且平台摊薄导致毛利率承压。

### 3.2 护城河趋势（过去5年 vs 未来5年）

- **过去5年**：两家护城河均**变宽**——受益于国产替代率从2019年14%→2025年24%（按价值），叠加海外交期长达2年的窗口。
- **未来5年预判**：
  - 中微：护城河宽度取决于**平台化第二曲线能否成功**（薄膜/EPI/量测）。若成功则从"窄深"变"宽深"，护城河大幅加宽；若失败则被锁在刻蚀单一品类，天花板受限。
  - 北方华创：护城河宽度取决于**能否把某些品类做到"深"**（如刻蚀追上中微、CVD追上拓荆）+ **毛利率能否止跌回升**。若毛利率持续下滑，说明平台广度未转化为定价权，护城河"虚胖"。

### 3.3 巴菲特式追问："10年后护城河还在吗？什么能摧毁它？"

- **能摧毁中微护城河的**：① 全球刻蚀龙头（LAM/TEL）技术迭代拉大代差（如原子层刻蚀ALE新范式）；② 平台化扩张失败、被锁死在刻蚀天花板；③ 尹志尧（82岁）之后技术判断力断层。
- **能摧毁北方华创护城河的**：① 各细分对手（中微/拓荆/盛美）在单品上持续超越，蚕食其"全"的价值；② 毛利率持续下滑证明平台化无定价权，沦为"组装厂"；③ 国资体制下研发效率与人才激励跟不上民营对手。

## 4. 逆向思考与风险清单 — 芒格"反过来想"

### 4.1 "这两家可能失败的所有路径"

| 失败路径 | 中微概率 | 北方华创概率 | 影响 |
|---------|---------|-------------|------|
| 下游晶圆厂capex周期反转（后周期行业） | 中 | 中 | 高（营收直接挂钩） |
| 平台化/新品扩张失败 | 中 | 低（已成型） | 高（中微）/中（北方华创） |
| 毛利率持续下滑，规模不经济 | 中 | **高**（已连续下滑，Q4仅37.15%） | 高 |
| 国产替代天花板（全球份额~5%封顶，缺海外客户） | 高 | 高 | 中 |
| 关键人风险（中微尹志尧82岁；北方华创国资体制） | **高（中微）** | 中 | 高 |
| 地缘管制升级切断核心零部件供应 | 中 | **高（自主率50-55%）** | 高 |
| 估值杀（当前PE 84-91x，全球龙头仅27-55x） | **高** | **高** | 高（当日已分别跌9.9%/6.7%） |
| 商誉减值（北方华创芯源微23.86亿商誉） | 低 | 中 | 中 |

### 4.2 历史类比

- **中微 ≈ 早期的LAM Research**：单点刻蚀技术起家的专精玩家。LAM靠刻蚀单赛道做到全球龙头、市值超3700亿美元——若中微复制此路径是巨大空间；但LAM的成功建立在**全球自由市场竞争获胜**，中微目前份额靠国产替代保护，含金量待验证。
- **北方华创 ≈ 中国版应用材料(AMAT)**：平台化全品类。AMAT毛利率48%+、ROE高、现金流强——北方华创毛利率40%且下滑、OCF/净利0.39，**"形似而神未至"**，平台化尚未转化为AMAT级的盈利质量。
- **警示类比**：芒格会警惕"3Com/思科式的周期顶点估值"——半导体设备是后周期行业，2026年处于历史高位（全球$1659亿、+23.2%），当景气见顶时，84-91x的PE会遭遇"戴维斯双杀"。

### 4.3 偏误自查

- **叙事偏差**：市场把"国产替代"叙事套在两家身上，赋予确定性溢价，掩盖了盈利质量的真实差异。
- **锚定效应**：投资者锚定52周高点（中微500、北方华创967），把当前价视为"跌下来的便宜货"，但PB/PE绝对值仍在历史高位。
- **幸存者偏差**：把中微类比LAM、北方华创类比AMAT，忽略了大量单赛道设备公司在竞争中消亡的案例。

### 4.4 芒格式追问："聪明人为什么会不买/做空？"

**空方核心论点（两家共通）**：
1. **估值**：PE 84-91x vs 全球龙头27-55x，PEG中微~1.8/北方华创~0.99——中微成长调整后仍贵。
2. **利润质量**：中微扣非增速仅11.64%、含26.62%非经常损益；北方华创归母净利真跌1.77%、OCF/净利0.39。
3. **周期顶点**：设备是后周期，2026景气历史高位，向下风险大于向上。
4. **国产替代天花板**：全球份额~5%封顶，缺海外逻辑/存储大客户。

> 当日（2026-08-03）中微-9.93%、北方华创-6.65%的大跌，正是市场对"高估值+利润质量存疑+周期位置高"的一次集中定价。

## 6. 行业与文明趋势 — 李录"文明演进框架"

### 6.1 行业范式判断

半导体设备是**AI文明的"卖铲人"**——处于李录意义上的"文明级范式转移"（AI/算力革命）的关键基础设施位置。

- **全球TAM**（SEMI，媒体转述）：2024约$1130亿 → 2025 $1350亿 → **2026E $1659亿(+23.2%，创纪录)**。
- **中国市场**：2025年$493亿，**占全球37%，全球最大**（自2020年起连续第一）。
- **WFE价值量结构**：薄膜22.9% + 刻蚀22.1% + 光刻21% ≈ 三大核心占66%；离子注入11.6%、清洗10%、炉管6.1%。
- **国产化率**（口径分歧大）：按价值全国全品类**约24%**（2019年14%→2025年24%）；部分成熟品类（刻蚀/清洗/CMP）**已超35-50%**；洼地（<25%）为**光刻、量测、离子注入、涂胶显影**。

### 6.2 两家在产业价值链的位置

- **刻蚀（22.1%价值量）**：中微在**高端介质刻蚀**占据国内制高点（进台积电5nm）；北方华创在**硅刻蚀**批量供货长鑫。两家在刻蚀细分侧重不同，直接竞争有限。
- **薄膜沉积（22.9%价值量，最大单一品类）**：北方华创规模领先（100亿+ PVD/CVD），中微是快速追赶者（5亿+224%）。**这是两家未来竞争最激烈的战场**。
- **光刻（21%）**：两家均**未涉足**——这是国产替代最硬的骨头（ASML EUV禁运），也是两家TAM的天花板所在。

### 6.3 下游需求（顺风）

- **中芯国际**2025 capex 81亿美元(+11%)，产能利用率>93%。
- **存储超级周期**：长鑫存储(CXMT)2026Q1营收+700%；HBM/DRAM扩产直接拉动刻蚀/薄膜/热处理设备需求。
- **国产DUV导入**：中芯2025年9月起验证国产DUV，规划2026年出货~5台、2027年~20台。

### 6.4 地缘政治（双向影响）

- **抑制端**：BIS实体清单持续升级（2026年3月蔡司取消EUV零部件订单）；CXMT技术上限被压制在15-17nm；2026年7月管制延伸至RISC-V开源架构。核心零部件（射频电源、分子泵、精密导轨）仍依赖美/日/德——**北方华创自主率50-55%的敞口高于中微（称基本100%自主）**。
- **刺激端**：海外设备交期长达2年，倒逼国产替代；高盛判断"中国DRAM产能扩张不可逆，设备国产化是最确定投资方向"。

### 6.5 李录式追问："20年后回看，是'这个时代的标准石油'还是'昙花一现的3Com'？"

- **乐观情景（标准石油）**：AI算力+存储超级周期+国产替代三重共振，两家成长为中国的LAM/AMAT，在全球设备格局中占据一席。
- **悲观情景（3Com）**：当前是周期+政策双重顶点，一旦景气反转或国产替代进入"内卷"（尹志尧自述"行业15种内卷"，新凯来等新玩家涌入），高估值遭遇戴维斯双杀。
- **李录的判断标准**：文明级机会要看**"没有政策保护时的真实竞争力"**。两家毛利率(~40%)仍低于全球龙头(48-52%)，说明**目前仍处"受保护的追赶期"，尚未证明自己是自由竞争中的赢家**。20年后的答案，取决于两家能否把"国产替代红利"转化为"全球竞争力"。
