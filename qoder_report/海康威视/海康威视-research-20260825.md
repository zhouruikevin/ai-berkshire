### 1.1 一句话定义

**海康威视的本质是"物理世界的感知与数字化"——以视频监控起家，靠硬件制造规模+渠道网络+AI算法三位一体，向千行百业输出感知设备与场景化数字化服务。** 它本质上是一家"卖硬件+软件+服务"的智能物联产品公司，而非纯安防公司。

### 1.4 收入漏斗分析（2026H1，年化口径）

```
[顶层业务量：智能设备年产能2.77亿台 × 平均单价 ~340元]
    │ 75%订单定制化，海外140+国家渠道网络
[营收 468.23亿（2026H1）]
    │ - 直接成本（元器件/存储采购、代工、物流）：-234.3亿
[毛利 234.0亿（毛利率49.97%）]
    │ - 研发费用 61.69亿（占营收13.2%，全部费用化）
    │ - 销售费用 ~52亿（渠道/海外办事处）
    │ - 管理费用 ~25亿（含股权激励）
[营业利润 ~95亿]
    │ - 财务费用 3.46亿（汇兑损失，+146.8%）
    │ - 税 + 少数股东损益 12.27亿（创新业务子公司的少数股东拿走）
[归母净利润 78.96亿（2026H1）]
    │ + 折旧摊销（非现金） - 资本开支 ~20亿
[自由现金流 ~75亿（2026H1估算）]
```

**漏斗关键发现**：
1. **漏损最重的环节是"少数股东"**：创新业务占营收32.4%，但利润的约一半归少数股东（萤石、机器人、微影等子公司引入外部资本）。2026H1少数股东损益+96.64%，归母弹性被稀释——这是海康与纯母公司模式最大的差异点。
2. **研发是第二大漏损**：每年117亿+研发费用化，占营收12.7%，这是护城河的"燃烧成本"，也是利润率上不去的核心原因。
3. **对比大华股份**：海康2026H1净利+39.57% vs 大华中报净利-3.74%，差异主因产品结构（创新业务）与费用管控。

### 1.6 段永平式追问

> **"这门生意好在哪？如果只能用一句话描述，是什么？"**
>
> 好在：**它是一个"卖铲子"的生意——所有行业数字化都要先装"眼睛"（感知设备），海康拥有全球最大规模的感知设备制造能力和最深的下沉渠道，且AI大模型把单位设备的价值量拉高了**（观澜编码技术同等画质省50%存储投入）。硬件+软件+AI三位一体，对手很难只靠资本复制。
>
> 但也要清醒：**它的生意本质是"制造+集成"，毛利率天花板受制于硬件属性，且政府客户占比高导致周期性明显**——这不是茅台，是"高科技制造龙头"。

## 二、护城河评估（巴菲特：经济护城河）

| 护城河类型 | 验证方法 | 评估 |
|---|---|---|
| 品牌/定价权 | 是否能在不损失销量情况下提价？ | **中等偏强**。2026Q1统一提价成功（钛媒体报道"涨价续命"），毛利率+4.78pct验证定价权；但提价部分靠低价库存结转支撑 |
| 转换成本 | 客户迁移到竞品的成本？ | **强**。视频监控系统软硬件深度绑定（NVR/DVR+平台软件+AI算法），政企项目迁移需整网重建，5-8年设备更新周期天然锁定 |
| 网络效应 | 用户越多产品越好？ | **中**。云眸/开放平台有弱网络效应（接入设备越多，算法数据越多），但非强网络效应生意 |
| 规模效应 | 规模带来的成本优势？ | **强**。全球市占率连续14年第一（约24-30%），年产能2.77亿台、3万+硬件型号、75%定制化订单——制造柔性+采购议价是硬壁垒 |
| 技术/专利壁垒 | 技术领先几年？能否被复制？ | **中**。观澜大模型+AI编码技术领先国内同行1-2年；但AI技术迭代快，海外（AI算法）仍有差距，实体清单限制先进制程芯片获取 |

### 护城河趋势判断

- **过去5年（2021-2026）：先收窄后重新变宽**。2021-2024年国内政企需求崩塌+大华贴身竞争，护城河显露出"需求依赖型"弱点；2025-2026年靠创新业务（机器人+47.6%、存储+88.2%、热成像+47.6%）和AI产品化重新拓宽。
- **未来5年（2026-2031）预判**：AI大模型落地（上千款AI产品）若持续兑现，护城河将从"制造规模"升级为"数据+算法+场景"三重壁垒；风险在于：①国内同行（大华、宇视）跟随AI化；②海外大厂（思科/安讯士）在AI算法层反扑；③美国制裁持续压制先进芯片供给。

### 巴菲特式追问

> **"10年后这条护城河还在吗？什么能摧毁它？"**
>
> 大概率还在——但形态会变。10年后海康可能更像"智能物联OS+设备制造商"而非"安防公司"。真正能摧毁它的路径：①**AI感知能力平民化**（通用大模型+廉价摄像头让任何小厂都能做"感知"），硬件+算法溢价消失；②**制裁升级**至断供核心芯片；③**创新业务分拆失控**，母公司沦为控股公司空心化。第①条是最现实的威胁。

## 三、逆向思考与风险清单（芒格：反过来想）

### 3.1 失败路径推演

### 3.2 历史类比

- **类比对象：思科（2000-2020）**。同为"卖铲子"公司，思科在网络设备周期顶部的教训是：硬件溢价随技术平民化而消失，必须转型软件/服务才能维持利润率。海康正处类似拐点——AI能否产品化决定它走思科的路还是微软的路。
- **类比对象：大华股份（2021-2025）**。大华营收仅为海康1/2.8，2026中报净利-3.74%，证明该行业"规模即壁垒"——小规模玩家的利润率波动更大。

### 3.3 偏误自查

- **叙事偏差**：市场把海康讲成"AIoT+分红价值股"双故事，注意两个故事都可能被证伪（AI落地慢/分红率不可持续）；
- **锚定效应**：PE 19.38倍"看着便宜"是相对历史（20-30倍中枢）的锚定，但若按成熟价值股（营收增速长期个位数）重估，19倍并不便宜；
- **幸存者偏差**：海康是安防行业洗牌后的幸存者，不代表行业整体机会。

### 3.4 芒格式追问

> **"我最可能在哪里犯错？聪明人为什么会不买/做空这家公司？"**
>
> 我最可能错在：**把"净利增速连续抬升"线性外推**——2026H1的+39.57%有涨价+低价库存+汇率三重顺风，剔除后真实增速可能只有15-20%。聪明人不买的理由：①**它是一家"增长降速的科技公司"**——营收增速0-12%，PE 19倍对科技股不贵，对"类公用事业股"不便宜；②**少数股东结构**让归母利润弹性永远打折；③**制裁悬顶**，海外天花板可见；④大股东是央企（中电科），公司治理取向是"稳定"而非"股东价值最大化"。
