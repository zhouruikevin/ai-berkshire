## 一、生意本质分析 — 段永平"对的生意"

### 一句话定义

**腾讯是中国数字生活的"操作系统"——以微信14.32亿MAU的社交关系链为不可迁移的底座，对流经这张网络的注意力（广告）、交易（支付/电商）、娱乐（游戏）与企业需求（云/企业微信）分层"收税"。**

数据显示，2025年游戏（含国内外）仅占总收入约32%，真正的生意本质是**一门"税收型"基础设施生意**：用户不是"顾客"，而是"基础设施依赖者"。

### 收入漏斗分析：从业务量到自由现金流，逐层标注去向（FY2025）

> 段永平的"对的生意"要看钱最终流向哪里。以下追踪一元收入从入口到股东回报的全路径：

```
【入口】微信/WeChat MAU 14.32亿 + 小程序活跃600万+ + 游戏长青矩阵
   │  （单季小程序交易额突破3万亿元，流量池不额外获客即可变现）
   ▼
【总收入】7,518亿元 (+14%)
   │  减：营业成本约3,293亿元（收入的43.8%——服务器/内容/渠道分成/支付通道成本）
   ▼
【毛利】约4,225亿元（毛利率56.2%，5年提升13pp）
   │  减：销售费用 + 一般行政费用（含研发857.5亿元）+ 新AI产品投入（2025约180亿）
   ▼
【Non-IFRS经营利润】约2,780亿元（Non-IFRS营业利润率约37%；剔除AI投入的ex-AI口径约43%）
   │  → IFRS净利润 2,248亿元 / Non-IFRS净利润 2,596亿元（+17%）
   ▼
【经营活动现金流】约3,031亿元
   │  减：资本开支 792亿元（年报口径；StockAnalysis口径875亿）
   ▼
【自由现金流】1,826亿元（年报口径，+18%）｜2,156亿元（StockAnalysis口径）
   │
   ├──→ 分红：每股5.30港元，总派息约486亿港元
   ├──→ 回购：2025全年约800亿港元（注销股本）；2026上半年约214亿港元（港股年内最大）
   └──→ 余量增厚净现金 + 战略投资组合（上市公允价值6,727亿 + 非上市账面3,631亿）
```

**漏斗解读**：这门生意的核心特征是——**从收入到FCF的"漏损率"低且在改善**。56%的毛利率意味着每一元收入里有5毛6是毛利；经营杠杆使Non-IFRS净利3年CAGR约31%远超收入增速。**观点/推测**：这是典型的"印钞机"财务结构，钱不缺，问题不在"能不能赚"，而在"AI时代要花多少钱守住入口（2026 Capex拟翻倍至1,800亿级）、以及地缘政治会不会切断这台机器"。

> **段永平式追问**：这门生意好在哪？如果只能用一句话描述，是什么？

> **反面**：但要诚实地看到，最赚钱的"注意力税"（短视频广告）赛道，腾讯是**追赶者**而非领先者（视频号广告加载率约4.4% vs 抖音10%+）；增速已从14%降档到9%，社交网络首现负增长。这门生意在变"精"（利润率升），也在变"窄"（收入增速降、边界收缩）。

## 二、护城河评估 — 巴菲特"经济护城河"

### 五类护城河逐一验证

| 护城河类型 | 强度 | 验证分析（事实+证据） |
|-----------|------|---------|
| **网络效应** | ★★★★★ | 微信14.32亿MAU，社交图谱不可迁移。600万+活跃小程序构成自增强循环——商家为获客加入→品类丰富→用户粘性提升→更多商家加入 |
| **转换成本** | ★★★★★ | 离开微信=同时放弃社交关系链+支付习惯+小程序数据+企业微信工作通讯。这是一个"无解的集体行动问题" |
| **品牌/定价权** | ★★★★☆ | 游戏IP矩阵（王者荣耀运营10年+长青、英雄联盟、VALORANT、三角洲行动）。广告"定价权以仓库形态存在"——加载率远低于字节，提价/增量空间大但尚未兑现 |
| **规模效应** | ★★★★☆ | 研发费用857.5亿分摊到14亿用户，边际成本趋近于零。游戏分发渠道优势——开发者需通过腾讯/网易才能高效触达10亿中国玩家 |
| **技术/AI壁垒** | ★★★☆☆（较上版微升） | **仍是最弱一环，但执行力在加速**：混元Hy3正式版上线（总参数295B/激活21B/256K上下文，OpenRouter第三方测评居前）、WorkBuddy发布三端首个通用智能体独立App。但元宝C端MAU仅5,735万，仍不足第一梯队一半。腾讯的AI优势不在"模型"而在"分发"——微信是全球最大的潜在AI Agent部署平台 |

### 独特竞争优势：身份 + 通讯 + 履约"三层卡位"

**观点/推测**：AI Agent时代真正的护城河检验，不是"入口会不会被绕过"，而是"交易能不能被绕过"：

```
L3 注意力/入口层 → 可能被AI助手部分绕过（豆包等），侵蚀有限（估计4-11%）
L4 履约层（支付牌照 + 资金账户 + 商户网络）→ 极难绕过
        任何AI Agent完成一笔真实交易，都绕不开支付与清结算
        微信是中国唯一"支付牌照+资金账户+商户网络"三要素齐备的平台
```

**证据表明**：金融科技及企业服务贡献30.5%收入，其本体是"履约租金"而非"入口流量"。即使AI改变了人机交互方式，只要交易发生在中国境内，腾讯的支付/履约层依然收租。这是护城河中最被低估、也最抗AI颠覆的一层。

### 护城河趋势分析

| 因素 | 方向 | 影响 |
|------|------|------|
| 视频号（无需新App应对短视频） | 拓宽 | 利用存量14亿用户开辟新变现层 |
| 小程序生态深化 | 拓宽 | 单季交易额突破3万亿，履约层加固 |
| 企业微信 + AI Agent（WorkBuddy三端独立App） | 拓宽 | 新增B端转换成本，覆盖30+行业 |
| 国际游戏首超100亿美元 | 拓宽 | 降低单一市场依赖 |
| 字节/米哈游崛起、元宝C端掉队 | 收窄 | 注意力层被侵蚀 |
| 云/MaaS掉队 | 收窄（已确认） | IaaS第五、MaaS前五开外；但2026 Capex翻倍或部分对冲 |

**总体评估**：过去5年护城河**大致稳定、略有拓宽**。核心层（身份/通讯/履约）在加固，外围层（注意力/云）在失守。这是一个"核心变强、边界收缩"的护城河。

> **巴菲特式追问**：10年后这条护城河还在吗？什么能摧毁它？
>
> 微信的社交图谱护城河极难被摧毁——它需要14亿人同时集体迁移，这在消费科技史上从未发生过。**最可能的威胁路径不是"另一个微信"，而是AI原生交互的范式转移**。但即便入口被部分绕过，履约层（L4）依然收租。**能真正摧毁它的两件事**：(1) 全新交互范式彻底取代App模式且微信AI Agent转型失败；(2) 非公司层面的系统性风险——VIE被否定或中美地缘政治导致强制剥离/退市。前者是慢变量，后者是尾部黑天鹅。

### 失败路径清单

### 补充：2026-07-22 盘中大跌归因（筹码面事件，非基本面）

> 本报告定稿当日（7-22），腾讯盘中一度大跌近6%至446.6港元，恒生科技指数午盘-2.11%。为避免读者误判为"基本面恶化"，此处专门归因。**结论先行：无任何腾讯经营层面的新利空，本次下跌是"筹码面+情绪面+资金面"三重叠加。**

**① 腾讯特有的直接催化剂——公募二季报"减持之王"（今日腾讯比同行跌得更狠的关键）**

- 数据显示：公募基金2026Q2披露完毕，**腾讯是公募二季度减持市值最多的个股，减持市值达187.37亿元，由此退出公募前十大重仓股行列**（来源：新浪财经）。

**② 板块获利回吐——前期涨太多、涨太快**

**③ 全球+A股资金再平衡（抽水效应）**

### 一个必须澄清的"口径错觉"：字节是否在广告上碾压腾讯？

**证据表明"碾压"论不成立**：字节约4,200亿广告收入中，约一半是电商内循环投流；剔除内循环后，外循环广告差距仅约1.4倍，且腾讯以每年约+2个百分点的相对速度提升份额。腾讯广告连续多季双位数增长（Q1 +20%）。**这是一个反共识但有数据支撑的判断**（数据为行业估算，字节非上市，置信度中等）。

### 一个必须澄清的"利好错觉"：13936终止 ≠ 地缘风险解除

**这是本期最需要冷静的地方。** 市场把"13936行政令终止"解读为地缘利空全面反转，但必须精确区分两类地缘风险：

| 地缘风险类型 | 内容 | 13936终止的影响 |
|-------------|------|----------------|
| **估值折价（资金面）** | 美资养老金/主权基金被迫将港股中资划为高风险、下调配置 | ✅ **实质改善**——限制松绑，被动资金有回流前提 |
| **经营风险（资产面）** | CFIUS审查腾讯对Riot/Epic持股、CMC采购禁令 | ❌ **未改善**——属不同法律框架，仍悬而未决 |

**结论**：13936终止修复的是"折价"，不是"经营风险"。看多者可以据此上调合理PE中枢，但**不能据此移除CFIUS强制剥离这条尾部风险**。
