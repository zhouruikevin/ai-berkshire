## 第一步：数据收集摘要

- **近5年归母净利（亿）**：12.60 → **19.48**(2022峰值) → 5.11 → **-3.08**(2024亏损) → 2.13(2025扭亏)。**强周期**。
- **2025分部（营收94.34亿）**：新能源材料（六氟为主）31.34亿（33.21%，毛利21.74%）、新能源电池28.49亿（30.21%，毛利12.57%）、氟基新材料27.89亿（29.56%，毛利9.05%）、电子信息材料~4.08亿。新能源合计~63.4%。
- **六氟**：2025出货约5万吨，全球市占~20-25%（第二，天赐第一~37%）；成本4.2-4.5万/吨，较行业低15-20%（第四代双釜法）。
- **大圆柱电池**：2025出货近10GWh（国内第一梯队），毛利仅12.57%。
- **财务**：2025毛利率13.96%、ROE 2.53%、经营现金流1.99亿；资产负债率2026Q1 59.83%（偏高）、有息负债94亿，"大存大贷"。

## 第二步：生意本质分析（段永平"对的生意"）

**一句话本质**：以六氟磷酸锂为核心的氟化工一体化企业，兼做大圆柱电池、半导体氟化学品、钠电材料。

**好生意吗？** 主业六氟是**强周期化工品**：
- **好的一面**：全产业链一体化（萤石→氢氟酸→氟化锂→六氟）、成本全球领先、涨价周期弹性大。
- **坏的一面**：六氟价格59万→5万→18万→10万剧烈波动，盈利完全绑定价格；电池业务毛利仅12.57%、氟基新材料毛利9.05%，多元化摊薄了整体回报；"大存大贷"财务结构不健康。

**本分**：李世江1999年创立、2009年攻克六氟打破日本垄断——**核心主业本分扎实**。但近年铺开大圆柱电池（规划200GWh）、半导体、钠电、固态多条战线，**摊子铺得过大**，2024年因电池产线+存货减值致巨亏33.66亿，是"偏离本分"的代价。

### 收入漏斗（2025，单位：亿元）

```
六氟需求（出货5万吨，全球市占~22%）+ 大圆柱电池10GWh + 氟基新材料
    │
营业收入 94.34（新能源材料33% + 电池30% + 氟基30% + 电子信息4%）
    │ - 营业成本（六氟成本4.2-4.5万/吨低于行业；但电池毛利仅12.57%、氟基9.05%拖累）
毛利 ~13（综合毛利率13.96%，2026Q1跳升至27.61%）
    │ - 期间费用（管理4.77亿+销售+研发~4-5%）- 财务费用（有息负债94亿，财务费用~1.8亿吞噬利润近半）
营业利润 ~3
    │ - 税
归母净利 2.13（净利率仅2.3%）
    │ + 折旧摊销 - 巨额资本开支（200GWh电池扩产，2025前三季投资净流出11.79亿）
自由现金流 估计为负
```

**漏斗核心洞察**：多氟多的漏斗有两个致命漏损——①**多元化拖累毛利**：高毛利六氟（21.74%）被低毛利电池（12.57%）和氟基（9.05%）稀释，综合毛利率仅13.96%；②**财务费用吞噬**：有息负债94亿、"大存大贷"，财务费用吃掉近半营业利润。**最核心问题在"多元化摊薄+高杠杆"这两层**——即便六氟成本领先，也被下游电池的重资产低回报和高财务费用侵蚀。

**段永平式追问**：好在哪？——**六氟成本领先是唯一真优势**。但公司把六氟赚的钱投进了毛利12%的电池和一堆概念，**"用好生意的钱补贴平庸生意"的反向操作**，段永平会皱眉：这不够本分，摊子太大。

## 第三步：护城河评估（巴菲特"经济护城河"）

| 护城河类型 | 强度 | 证据 |
|---|---|---|
| 品牌/定价权 | ★★☆ | 大宗化工品，无定价权 |
| 转换成本 | ★★☆ | 六氟认证有黏性，价格敏感 |
| 网络效应 | ★☆ | 不适用 |
| 规模效应 | ★★★★ | 六氟全球第二、产能6.5万吨、成本低15-20% |
| 技术壁垒 | ★★★ | 第四代双釜法（万吨投资降至1.8亿）、电子级六氟全球>60%、G5级氢氟酸 |

**护城河趋势**：六氟成本护城河**稳固但相对**——2026年行业重启扩产（规划>100万吨）、价格从18万回落至~10万，护城河变现能力随周期收窄。半导体氢氟酸有技术壁垒但**对业绩贡献极低（董秘澄清）**，护城河"标签化"。

**巴菲特式追问**：10年后护城河还在吗？——**六氟成本优势大概率在**（一体化、氟资源），但护城河转化利润的能力随周期波动，且被多元化摊薄。什么能摧毁它？——六氟长期过剩使价差消失、大圆柱电池竞争失败拖累、高杠杆遇周期下行。

| 失败路径 | 概率 | 影响 |
|---|---|---|
| 六氟价格回落（2026重启扩产、下游补库结束） | 中高 | 高——2026Q2净利已环比腰斩 |
| 净利基数薄+PE高（73倍），预期落空 | 中高 | 高——估值下杀 |
| 大圆柱电池200GWh扩产失败/毛利过低 | 中 | 高——重演2024减值巨亏 |
| 高杠杆（负债60%、有息94亿）+大存大贷 | 中 | 高——财务风险 |
| 半导体等概念证伪（已发生，7/29跌停） | 高 | 中——估值溢价消失 |
| 家族治理（亿丰电子关联收购、减持） | 中 | 中 |

**历史类比**：多氟多自身2022（净利19.48亿）→2024（亏3.08亿）是周期教训。叠加2024年电池产线减值33.66亿，是"多元化激进扩张遇周期下行"的经典案例。

**芒格式追问**：聪明人为什么不买/做空？——因为**PE 73倍+净利基数薄+2026Q2环比腰斩+半导体概念证伪+股价7月已腰斩（57.5→25.5元）**。市场先炒概念、再证伪。我最可能犯的错：把多个热点标签叠加成"多重成长"，而实际每个都单薄。**芒格会说：这是一个讲太多故事的公司，反过来想，故事越多越要警惕。**

**空方核心论点**：①业绩完全绑定六氟价格，当前从峰值18万回落至10万，2026Q2环比腰斩，周期见顶；②估值贵（PE-TTM 73-78倍/静态178倍/PB 4.3倍历史高位），净利基数薄；③高负债+大存大贷+财务费用吞噬+应收激增+募投延期+家族减持与治理争议（亿丰电子）；④半导体概念被董秘证伪。

## 第六步：行业与文明趋势（李录"文明演进框架"）

- **文明级趋势**：电化学储能，六氟是电解液核心原料。但多氟多的多元标签（大圆柱、半导体、钠电、固态）**真伪混杂**。
- **TAM**：六氟2025全球出货27.9万吨（+35%）、中国占94%；LiFSI（下一代锂盐）2025有效产能5.8万吨；半导体湿电子化学品受国产替代催化但多氟多贡献低。
- **价值链位置**：六氟CR3>66.8%，多氟多全球第二（~22%），天赐第一（~37%）。

**李录式追问**：20年后回看是"标准石油"还是"3Com"？——**六氟业务是隐形冠军的候选（成本领先），但整体公司因多元化和高杠杆更接近"什么都想做的追随者"**。相比天赐（电解液专注龙头），多氟多的战略聚焦度和资本纪律更弱，长期终局不确定性更高。

## 第七步：估值与安全边际（巴菲特"内在价值"+段永平"对的价格"）

**当前定价**：PE(TTM) ~73倍（历史~77%中高分位）、静态PE 178倍、PB ~4.3倍（历史高位）。**2026E动态PE约14-18倍**（机构一致预期净利21.22亿）——但2026Q2净利已环比腰斩，全年21亿预期存下修风险。

**反向DCF**：当前381亿市值+PE 73倍，隐含"2026净利大幅改善且可持续"，即**押注六氟维持高价+多元业务放量**——两个假设都不稳固。

### 三情景估值（工具计算，以2026E EPS≈1.79元为基，**周期股+预期下修风险，仅供参考**）

| 情景 | 年增速 | 目标PE | 3年后目标价 | 涨跌幅 |

| 乐观（六氟维持+电池放量） | 10% | 20x | 47.6 元 | +49.0% |

## 结论：AI 分析置信度 vs 投资确定性

- **高确定性结论（数据充分）**：六氟全球第二/成本低20%、2025扭亏2.13亿、2026Q1爆发/Q2环比腰斩、PE 73倍历史中高分位、有息负债94亿——扎实。
- **有限信息推理（需谨慎）**：2025研发费用、2023经营现金流、EV/EBITDA、各分部精确毛利对比——**数据不足**。
- **投资确定性核心变量**：**六氟磷酸锂价格** + **多元化业务（尤其大圆柱电池）能否创造正回报**。多氟多是五家中**基本面最弱、估值最贵、管理层评分最低、风险收益比最差**的一只——概念多、周期性强、高杠杆、治理有瑕疵。

> **风险提示**：本报告为研究分析，非投资建议。多氟多估值偏高且周期见顶迹象明显，请谨慎。数据以2026半年报为准。
