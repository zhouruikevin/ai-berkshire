### 1.1 一句话定义

**紫光国微的本质是"特种半导体（军工电子）平台型公司"——以FPGA、特种存储、特种模拟芯片为核心的国产替代龙头，叠加智能安全芯片（eSIM/银行卡）现金流业务，Fabless轻资产模式，高毛利、高资质壁垒、订单驱动。**

### 1.4 收入漏斗分析（2026H1）

```
[顶层业务量：特种IC订单额（公司不披露）+ 智能卡/eSIM出货量（全球400+运营商适配）]
    │ 特种IC：资质壁垒+型号列装，订单-收入转化有1-2年周期
[营收 34.43亿（2026H1，+13.0%）]
    │ - 直接成本（晶圆代工、封测）：-16.0亿（毛利率53.59%）
[毛利 18.45亿]
    │ - 研发费用 6.40亿（占营收18.6%，全年口径24.6%）
    │ - 销售+管理费用 ~4.5亿（含股份支付0.54亿）
[营业利润 ~7.5亿]
    │ - 税 ~1.5亿
[归母净利润 7.98亿（2026H1）]
    │ + 折旧摊销 - 资本开支 ~2亿（2025全年3.78亿）
[自由现金流 ~6亿（2026H1；2025全年仅3.88亿）]
```

**漏斗关键发现**：
1. **漏损最重的环节是"晶圆代工+封测"**：Fabless模式的直接成本中，先进制程晶圆（FPGA对制程敏感）与封测成本占比高，且议价能力弱于IDM；
2. **研发是第二漏损**：研发总投入占营收24.56%（2025），FPGA需每2-3年推新一代产品——这是维持特种IC 70%毛利率的代价；
3. **漏斗最窄的环节是"订单转化"**：军品从订单到收入确认周期长、波动大，导致自由现金流极不稳定（2023年15.18亿 → 2025年3.88亿 → 2026H1回升）。

### 1.5 商业模式画布

| 维度 | 特征 |
|---|---|
| 收入模式 | 特种IC（型号列装，一次性+持续供货）+ 智能安全芯片（eSIM/银行卡，量大利薄） |
| 复购驱动 | 型号列装后生命周期内持续供货（"定型即锁定"）+ FPGA软硬件绑定（布局布线只能在厂商EDA完成，跨代际黏性） |
| 客户结构 | 军工集团下属院所（保密，不披露）+ 三大运营商 + 全球400+运营商 |
| 成本结构 | Fabless轻资产：晶圆代工+封测外包，2025H1自建封装线投产提升自主保障 |
| 生态粘性 | 特种IC认证周期长、替换成本极高；eSIM已适配全球400+运营商 |

### 1.6 段永平式追问

> **"这门生意好在哪？如果只能用一句话描述，是什么？"**
>
> 好在：**它是一个"高毛利+高壁垒+长周期"的特种生意——FPGA/特种IC一旦列装，客户十年不换供应商，毛利率70%是军工行业'先款后货+型号垄断'的自然结果**。而智能安全芯片提供了现金牛。
>
> 但也要清醒：**它的收入和利润节奏自己说了不算——军品订单的节奏由军方采购计划决定，2024年净利-53%就是明证**。这是一门"好生意"但不是"好预测的生意"。

## 二、护城河评估（巴菲特：经济护城河）

| 护城河类型 | 验证方法 | 评估 |
|---|---|---|
| 品牌/定价权 | 是否能在不损失销量情况下提价？ | **强**。特种IC毛利率70%+，军工定价机制（成本加成+型号垄断），提价能力极强；但受军费预算约束 |
| 转换成本 | 客户迁移到竞品的成本？ | **极强**。FPGA布局布线只能在厂商自有EDA完成，软硬件深度绑定；型号列装后替换需重新走完整个认证流程（数年周期） |
| 网络效应 | 用户越多产品越好？ | **无**。非网络效应生意 |
| 规模效应 | 规模带来的成本优势？ | **中**。Fabless模式下规模效应有限；但国产特种IC市场玩家少（复旦微、国芯科技、振华风光），先发者具供给稀缺性 |
| 技术/专利壁垒 | 技术领先几年？能否被复制？ | **中-强**。国产FPGA整体落后国外（Xilinx/Intel）1-2代制程；国内第一梯队（紫光国微/复旦微）之间差距小，专利+工艺+生态锁定形成壁垒 |

### 护城河趋势判断

- **过去5年（2021-2026）**：护城河**显著变宽**——国产替代加速（中美科技脱钩）、自建封装线投产、新品（图像AI智能芯片、域控芯片）导入，特种IC从"能用"走向"好用"；
- **未来5年（2026-2031）预判**：国产替代逻辑持续，但**竞争加剧**——复旦微电获上海国资加持、国芯科技等扩产，特种IC从"卖方市场"走向"寡头竞争"；智能安全芯片价格战持续（2026H1毛利率-5.08pct已显疲态）。

### 巴菲特式追问

> **"10年后这条护城河还在吗？什么能摧毁它？"**
>
> 大概率还在——军工行业的认证周期决定了"在位者优势"。但摧毁路径有三：①**军品定价改革**（若推行市场化降价机制，70%毛利率不可持续）；②**国产FPGA内卷**（复旦微28nm主力+1xnm FinFET推进，若其先进制程率先突破，紫光国微的先发优势被削弱）；③**大股东变动**（无实际控制人结构，智路建广若退出，战略连续性存疑）。

## 三、逆向思考与风险清单（芒格：反过来想）

### 3.1 失败路径推演

| 失败路径 | 概率 | 影响 | 逻辑 |
|---|---|---|---|
| 军品订单再次断崖（2027-2028采购空窗） | 中 | 高 | 2024年净利-53%的前车之鉴；公司自己承认"2026/2027年订单情况难以预测" |
| 毛利率持续下行 | 中高 | 中高 | 特种IC毛利率连续下滑（70.26%→69.68%），智能安全芯片竞争加剧（-5.08pct）；FPGA降价曲线陡峭（出货顶峰在第5-6年，约60%收入发生在前6年） |
| FPGA技术代差拉大（先进制程被卡） | 中 | 高 | 国产FPGA整体落后Xilinx/Intel 1-2代；若高端制程代工受限，产品升级受阻 |
| 智能安全芯片价格战吞噬利润 | 高 | 中 | 2026H1仅+0.96%，毛利率-5.08pct；智能卡行业竞争激烈 |
| 大股东/治理风险 | 低-中 | 中 | 紫光集团重整后无实际控制人；19亿收购瑞能半导体尚在审核，存在不确定性 |
| 商誉减值 | 低 | 中 | 商誉6.86亿元（恒定），主要来自历史并购（同创国芯等），若特种IC景气长期低迷存在减值风险 |

### 3.2 历史类比

- **类比对象：2008-2012年的军工电子板块**。相似处：高景气→订单断崖→复苏的周期循环；教训是**军品公司不可用线性外推估值**，市场给予的PE波动极大（景气顶部15-20倍、底部40-60倍）。
- **类比对象：赛灵思（Xilinx，被AMD收购前）**。FPGA生意的全球范本：技术代际领先+生态锁定（Vivado工具链），利润率极高；紫光国微走的是同样的路，但受制于制程代差与军品保密。

### 3.3 偏误自查

- **叙事偏差**："国产替代+军工信息化"叙事极易让AI乐观化，需用2024年-53%的净利现实对冲；
- **锚定效应**：PE_TTM 33.59倍"看着贵"，但军工股在复苏期普遍享受40-60倍PE——锚定对象选错会误判；
- **幸存者偏差**：紫光国微是紫光系破产重整后活下来的公司，同系公司（紫光存储等）的命运提醒我们大股东风险真实存在。

### 3.4 芒格式追问

> **"我最可能在哪里犯错？聪明人为什么会不买/做空这家公司？"**
>
> 我最可能错在：**把2026Q1的+180%净利增速当成常态**——那是低基数（2025Q1净利仅1.19亿）的假象，2026H1增速已回落至+15.29%，全年大概率回归20-30%区间。聪明人不买的理由：①**自由现金流太差**——2025年FCF仅3.88亿，P/FCF高达133倍，利润质量存疑（应收/存货占用）；②**治理结构复杂**——无实际控制人+重整后遗症；③**订单不可见**——军品公司是"黑箱"，机构无法跟踪季度订单；④**估值已反映复苏**——33.59倍PE_TTM意味着市场已把2026-2027年复苏定价。

## 五、行业与文明趋势（李录：文明演进框架）

### 5.1 是否处于文明级范式转移？

**是——但位置特殊**。全球正处在"AI+半导体自主化"的范式转移期：中国半导体国产替代是**文明级事件**（技术主权争夺），特种IC是其中**确定性最高**的子领域（国防需求不可贸易化、不可妥协）。紫光国微站在"军工信息化+国产替代"的双重趋势交汇点。

### 5.2 TAM与增长曲线

| 市场 | 规模/特征 | 增速 | 紫光国微位置 |
|---|---|---|---|
| 中国特种IC市场 | 数百亿级（估算，保密） | 景气周期波动，长期随国防预算+信息化率提升 | 第一梯队（与复旦微并列） |
| FPGA市场 | 全球约100亿美元级 | 国产替代加速 | 国产FPGA双雄之一 |
